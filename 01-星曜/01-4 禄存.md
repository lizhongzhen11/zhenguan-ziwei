# 01-4 禄存

# **一、基本信息**

禄存，又名禄星、天禄星。五行属己土（阴土），北斗第三星（即天玑星），真人之宿，主人贵爵，掌人寿基。化气为富，为财禄之星。是一颗大吉星，十二宫中皆为福论，并有解厄制化之功。

# **二、核心性质**

1. 主财禄、衣食、贵爵、寿基。是正财之星，非横财。古人讲"有土斯有财"，禄存的财是田地、牧场、房产、一砖一瓦攒出来的，是种出来的、养出来的。

2. 主静、主藏、主守。禄存的"存"字就是储存、保存的意思。它代表积累、保护、稳固，而非流通和变化。

3. 解厄制化之星。禄存能解巨门之暗（土克水），能解廉贞、七杀、破军、贪狼之恶。落诸宫皆能降福消灾，但忌冲破。

4. 锦上添花之星，不主雪中送炭。命宫正曜须有力，禄存才能发挥锦上添花之效。若正曜无力，禄存亦难施力。

5. 随主星而旺衰。禄存本身不能独立施力，须依附主星才能发挥作用。

# **三、羊陀夹——禄存最重要的结构特征**

禄存永远被擎羊（在前一宫）和陀罗（在后一宫）所夹。这是由安星法决定的：擎羊在禄存前一宫，陀罗在禄存后一宫。

这意味着：

- 禄存所在宫位的前后两邻宫，必有擎羊和陀罗。

- 赚取钱财的同时，必带有是非与劳累。天下间无唾手可得的正财。

- 禄存单守命宫（无主星同宫）时，六亲缘薄，有孤克之象；逢煞者形势伤之一层（⚠ **该层断语原文不入库**，属《05-4》§四.5 形伤域）。
    - ⚠ **出口**：六亲一层只出关系层；形伤一层**可转译为防护提示**（"**宜留意意外伤害与职业防护**"），**不指伤处、不给时间点**。

- 若化忌与禄存同宫，被羊陀所夹，则为"羊陀夹忌"，是凶格，破坏本宫。

# **四、禄存与化禄的区别**

禄存是实体星曜，化禄是四化之气。二者有本质不同：

- 禄存主静、主藏、主守，是实实在在的贵气和钱财，是"存"。

- 化禄主动、主流通、主变化，依附于星曜之下，是"化"。

- 禄存代表积累、保护、稳固；化禄代表流通、分享、机遇。

- 禄存是"爵禄"之星，很实际，年限遇到它总有好事；化禄是不可捉摸的"气"，只能依附于其余星曜之下。

二者同会于命宫三方四正，则为"双禄朝垣"，是顶级富贵格局。

# **五、喜入宫位**

禄存喜入命宫、身宫、财帛宫、田宅宫、官禄宫、福德宫，皆为庙旺之地，一生富足。

禄存入六亲宫中的兄弟、夫妻、子女、父母四宫主孤克，缘分较薄。

- 入命身：一生衣食无忧，稳重厚道。

- 入财帛：财运亨通，有积累财富的能力。

- 入田宅：有祖产可继，房产多。

- 入官禄：反为权，得掌权威。

- 入夫妻：因婚而贵。

- 入迁移：出外向贵。

- 入疾厄：五行属土，主脾胃问题。

# **六、与主星的配合**

- 与紫微、天相同度：主权力、权威。

- 与太阳、太阴同度：增日月光辉。

- 与天府、武曲同度：财富巨万。

- 与天机同宫：高艺随身。

- 与天梁同度：增荫庇之力。

- 与天同同度：增福寿之力。

- 可解廉贞、七杀、破军、贪狼之恶。

- 解巨门之暗（土克水，巨门属阴水）。

- 与天寿同在命宫：往往长寿。

注意：紫微禄存同宫，体态虽丰厚，但神孤（王亭之《形性赋》注）。

# **七、重要格局**

1. 双禄朝垣：禄存与化禄分处命宫三方四正（命宫、财帛宫、官禄宫、迁移宫），主大富大贵。

2. 双禄夹命：禄存与化禄夹命宫。经云："化禄及禄存夹身命，主荣华富贵。"

3. 禄马交驰：禄存（或化禄）与天马同宫或对宫。主发财异乡，动中求财，事业上多奔波劳碌而招财。最佳配置是禄与马分处对宫（禄在对宫，天马在本宫），天马将禄运送到本宫。经云："禄马最喜交驰"、"天禄天马，惊人甲第"。

4. 羊陀夹命：禄存坐命，被擎羊陀罗夹住。非大凶格，但主孤克、六亲缘薄、靠自我奋斗。只要主星得力、无煞忌冲破，对事业影响不大，但对性情影响较大。

5. 羊陀夹忌：化忌与禄存同宫，被羊陀所夹。是凶格，破坏本宫，逢引动较凶。

# **八、性格特征**

禄存入命者：

- 稳重厚道，聪明有机变，多学多能。

- 生性节俭，不喜浪费，有很强的经济观念。

- 行事稳健沉着，稍有被动的倾向。

- 信义卓著，聪明耿直。

- 若独守命宫无主星：心眼小，逢煞则形貌孤寒，性情孤独刻薄。

- 乘旺有君子之风，博学多能。

# **九、忌与注意事项**

1. 忌单守：禄存无主星同宫则不能施力，仅为守财奴。

2. 忌冲破：被煞星（火铃空劫等）冲破则减力。

3. 忌与化忌同宫：形成羊陀夹忌，大凶。

4. 禄存为羊陀所夹，代表赚钱必带是非与劳累，无唾手可得之正财。

5. 禄存虽为大吉星，但亦主孤寡（"亦主孤寡"），不可只看到财而忽略孤的一面。

# **十、与天马的关系**

禄存与天马虽不成严格对星，但两星组合成"禄马交驰"格时，需二者联动，主动中得财。禄存好比白花花的钞票，天马如同运钞车。禄马交驰格中，禄存负责福财，天马负责运送。

注意：禄马交驰中的"禄"，严格来说以禄存为正（天禄），化禄亦可。但禄存与天马同宫时，因禄存被羊陀夹，天马亦受牵连，不如禄与马分处对宫为佳。
