# 01-6 红鸾天喜

# **一、星曜定位与级别**

红鸾、天喜在紫微斗数里属于乙级星，它们不属于北斗、南斗或中天的任何主星群，而是由出生年的地支来定位，落在十二地支宫位上，属于"地气"层面的星。在桃花星的谱系里，贪狼、廉贞是甲级桃花，红鸾、天喜、天姚、咸池、沐浴通常被列为次级桃花；其中红鸾、天喜属于"正桃花、吉桃花"那一类，色彩偏庄重、明朗，跟天姚、咸池那种偏肉欲、偏暗的桃花性质不同。

# **二、五行与阴阳**

红鸾星五行属水，为阴水，即癸水；天喜星五行属水，为阳水，即壬水。因为一阴一阳、又都属水，所以两星天然带"感情、姻缘、喜庆"的水性桃花色彩，且彼此呼应。论事时，红鸾偏主"婚姻之喜、嫁娶、结合"，天喜偏主"缘订、喜庆、添丁生育、团聚"。简单记：红鸾管"成婚"，天喜管"添喜（尤其添丁与各类喜事）"。

# **三、星性（性格与气质层面）**

红鸾的星性是开朗、直爽、亲切、含蓄，容易让人亲近，带一点虚荣与流荡、多变的色彩，主人重仪表、爱美、异性缘佳。坐命身者，男多相貌堂堂，女多容颜秀丽，禀性温良。

天喜的星性是喜热闹、自视较高、爱表现，主人容貌俊美、平易近人、有人格魅力，但单论桃花指数，天喜通常被认为略低于红鸾。

红鸾坐命、天喜自对宫照命（即命宫得鸾喜交会），或天喜坐命、红鸾照命，命宫的异性缘与表现欲会被进一步放大。注意红鸾与天喜恒处对宫，绝无同宫之可能，故此处只能是"一星坐、一星照"的交会关系，不可写作"同宫"。

# **四、庙旺与落陷（带流派色彩，见文末说明）**

不少派别给红鸾论庙旺：入庙主男招美妻、女配贤夫，富贵绵长、美貌美事；失陷则吉力减弱，喜庆之事易有波折或落空。**旺度状态以盘面标注为准，本档案不列地支**。天喜一般不单独细论庙旺，多随红鸾及同宫主星的庙陷而走。这一条各派口径不一，使用时建议作为"加权参考"而非铁律。

# **五、在十二宫的常见取象（按"宫位=作用域"来读，别张冠李戴）**

读这两颗星一定要先锁作用域：它落在哪个宫，就主要在"那个宫代表的人事"上发作，不要把它在夫妻宫的含义套到命宫的性格上。

落命宫或身宫：主其人重形象、有亲和力、异性缘好，感情上较早熟、较早有缘分；红鸾偏早婚或早定情缘，天喜偏容貌出众、讨喜。

落夫妻宫：是这两颗星最"对位"的宫位，主婚恋缘美、配偶条件或外形不错、婚姻带喜庆色彩；会天喜尤利婚缘与婚后添丁。

落子女宫：偏主添丁之喜、子女缘、与晚辈的喜庆互动，天喜在此添丁意味更浓。

落财帛宫：主"喜财"，即靠婚庆、喜庆、演艺、美容、公关、人缘相关行业得财，或因喜事进财；但若单守而无吉、又见耗星，则易因喜庆、面子、异性而破费，甚至喜投机。

落福德宫：主内心重享受、重美感、精神上有喜庆满足感，也主感情生活丰富。

落迁移宫：主出外人缘好、易得异性或贵人照拂、在外有喜庆际遇。

落官禄宫：主人缘助力事业、适合需交际与形象的行业，喜事多与事业节点相关。

落疾厄宫：这里要转"凶象"读法——红鸾、天喜属水带血气，落疾厄或与煞曜同会时，主血光、手术、产厄、妇科或泌尿系统问题，女命尤需注意经期与生育相关；这是"喜星见血"的取象，不可一律当吉。

落其余宫位（兄弟、交友、田宅、父母等）：按该宫人事叠加"喜庆、人缘、姻缘色彩"去读，例如田宅见之主家有喜事、置产之喜或家中人口增添。

# **六、与四化的关系**

红鸾、天喜是乙级杂曜，绝大多数流派不给它们排"生年四化"，也就是它们本身不化禄、化权、化科、化忌。它们的作用方式是"被引动"：当流年或大限的四化（尤其化禄、化科）飞入红鸾或天喜所在宫位，或流年的禄存、天马、红鸾、天喜叠到本命夫妻、命、子女等宫时，就是"红鸾星动"的应期，主该年婚恋、添丁、喜庆之事被触发。所以在工作流里，红鸾天喜更适合作为"应期标记星"来用，而不是作为四化的发射源。

# **七、组合与碰撞**

红鸾或天喜与天姚同宫：桃花色彩大增，主风流、感情丰富；但若逢正经婚缘引动，反而能"以喜制姚"，把天姚的偏邪桃花收成正缘婚姻，这是"吉桃花约束烂桃花"的典型。

红鸾或天喜与咸池、沐浴同会：肉欲与暗桃花色彩加重，需结合主星与煞曜判断是风流还是失足。

红鸾逢孤辰（或寡宿）：成"孤鸾"之象，主姻缘易迟、易错过，强求反有伤痛，是"喜星被孤克"的组合，论婚要打折。

红鸾或天喜与煞曜（擎羊、陀罗、火星、铃星）同宫：喜庆带波折，婚恋易有争吵、拖延或先苦后甜；落疾厄则血光、手术意味更实。

红鸾或天喜与大耗同度，又入命或财帛：主因喜庆、面子、异性而耗财。

红鸾或天喜与昌曲、左右、魁钺等吉星同会：婚缘与人缘之美被放大，主得配偶或异性之助、喜事顺遂。

红鸾天喜与本命禄存、化禄相会：喜庆带财，婚喜与进财同至。

# **八、应期与"红鸾星动"的断法**

"红鸾星动"的应期判断，本质是**多层鸾喜在多层宫位上发生"叠"（重合）**，再配合引动条件，才落实为事件。涉及三层星、三层宫，交叉组合如下：

**三层星（由静到动）：**

- 本命红鸾天喜：由生年支安出，一生不变，是婚恋喜庆的静态底色坐标。

- 大限红鸾天喜：由大限所值地支安出，每十年变一次，定该十年的婚恋喜庆基调。**注意：此层为部分派别采用（尤其重岁建、重飞星者），另一部分派别只认本命+流年两层，不安大限鸾喜。默认看本命+流年，若启用大限鸾喜，须与本命鸾喜、大限四化交叉印证，不单凭大限鸾喜下结论。**

- 流年红鸾天喜：由流年地支安出，每年变一次，是"红鸾星动"最直接的触发信号。

**三层宫（由内到外）：**

- 本命盘的命宫、夫妻宫、子女宫（一生婚恋的根基宫位）。

- 大限盘的命宫、夫妻宫、子女宫（该十年婚恋的主战场）。

- 流年盘的命宫、夫妻宫、子女宫（该年婚恋的具体落点）。

**"叠"的交叉组合（任一组成立即构成鸾喜触发条件之一）：**

1. 流年红鸾或天喜叠入**本命**命宫、夫妻宫、子女宫（最常见、最经典的"红鸾星动"）。

2. 流年红鸾或天喜叠入**大限**命宫、夫妻宫、子女宫（该年婚恋信号落在十年主战场上）。

3. 流年红鸾或天喜叠入**流年**命宫、夫妻宫、子女宫（该年自身宫位直接逢鸾喜，主该年人缘、喜庆氛围最浓）。

4. 大限红鸾或天喜叠入**本命**命宫、夫妻宫、子女宫（若启用大限鸾喜，则定该十年婚恋底色与本命根基共振）。

5. 大限红鸾或天喜叠入**大限**命宫、夫妻宫、子女宫（若启用大限鸾喜，则该十年自身宫位逢鸾喜，主十年内婚恋喜庆基调明显）。

6. 大限或流年的命宫、夫妻宫、子女宫**走到**本命红鸾或天喜所在宫位（即宫位动到星上，与上述"星叠入宫"是同一事件的反向表述，实质等价）。

**引动条件（必须叠加，否则不落实）：**

上述任何一种"叠"成立后，还须该年（或该限）有以下至少一项引动，才主婚恋、定情、结婚、添丁等实事落实：

- 四化引动：流年或大限四化（尤其化禄、化权）飞入上述被叠之宫，或飞入其对宫、三方。

- 禄马引动：流年禄存、天马落入或照入上述宫位。

- 主星吉化：该宫主星本身逢吉化（如化禄、化权）或逢吉星（昌曲、左右、魁钺）同宫或会照。

**无引动时的读法：**

单见鸾喜叠宫而无任何引动（无四化、无禄马、无主星吉化），往往只是"有人缘、有暧昧、有喜事氛围、有社交活跃"，未必落实成婚或添丁。断事时不可把"见鸾喜"直接等于"必结婚"。

**多层叠加时的力度递增原则：**

叠的层数越多、引动越强，事件越落实、越重大。例如：流年鸾喜叠入本命夫妻宫，同时大限鸾喜也在该宫，同时流年化禄飞入该宫——三层星叠同一宫加四化引动，主该年婚恋大事几乎确定。反之，仅单层叠、无引动，则仅为氛围。

# **九、年龄段的吉凶倾向（古籍常见说法）**

古诀多论：早年（约第三大限之前）逢红鸾天喜，主婚喜、人缘、喜庆，多吉，亦偶带升迁之喜但力弱；中年逢之，主添丁、喜庆团聚，若无添丁则转为桃花。
