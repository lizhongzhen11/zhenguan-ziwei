# 01-3-4 铃星

## 一、基本性质

- 五行：阴火（丁火）

- 性质：煞星（六煞之一）

- 化气：杀

- 代表：暗中的压力、慢性困扰、阴沉、嫉妒、记仇、暗中爆发、精神折磨、冷暴力

- 与火星的区别：火星为阳火（明火），主明面上的突发暴烈，来得快去得也快；铃星为阴火（暗火），主暗中的潜伏压力，来得慢去得也慢，但更持久、更阴沉、更难防备。古诀称"火明铃暗"。

## 二、庙陷

- 入庙：凶性被制，阴沉转化为深沉冷静、有谋略、有持久力，主"铃星得用，惊险中求富贵"。

- 得地：凶性稍减，主有急智、反应快。

- 利益：凶性有所转化，主有表现力。

- 落陷：凶性全开，主阴沉、嫉妒、记仇、暗中伤害、精神压力大。

## 三、铃星在十二宫

> 以下为铃星落入各宫时，该宫所主之事带有的铃星性质。具体吉凶需结合主星、四化、其他辅星综合判断。
> 
> 

- **在命宫：** 性格阴沉、固执、记仇，表面冷静内心激烈，有谋略但心胸较窄。入庙则主深沉有魄力，落陷则主阴沉多疑。

- **在兄弟宫：** 与兄弟朋友关系表面平静、暗中紧张，易有冷战、暗中较劲。

- **在夫妻宫：** 婚姻中多冷战、暗中不满、精神折磨，感情问题不爆发但持续侵蚀。

- **在子女宫：** 与子女关系表面疏离、暗中紧张，或生育过程有暗中波折。

- **在财帛宫：** 求财过程有暗中阻碍、慢性消耗，或因嫉妒、计较而错失机会。

- **在疾厄宫：** 主慢性病、精神压力、失眠、焦虑、暗中积累的疾病。

- **在迁移宫：** 在外做事有暗中阻碍、慢性压力，进展缓慢且令人焦虑。

- **在交友宫：** 与朋友下属关系表面和气、暗中较劲，易遇暗中使绊之人。

- **在官禄宫：** 工作中有暗中竞争、慢性压力，或因嫉妒、记仇而影响事业发展。

- **在田宅宫：** 家宅不宁，暗中有纠纷、精神压力大，居住环境令人压抑。

- **在福德宫：** 内心焦虑、多疑、记仇、精神内耗严重，难以真正放松。

- **在父母宫：** 与父母长辈关系表面平静、暗中紧张，易有冷战、暗中不满。

## 四、铃星与其他星曜的组合

> **原则：** 以下只写两星同宫或对宫时的**组合性质**（两星如何交互），不绑定具体宫位。具体应验在哪方面，取决于实际落在哪个宫。
> 
> 

### 铃星 + 贪狼（铃贪格）

- **同宫：** 贪狼的欲望与铃星的暗火同处一宫，该宫所主之事带有"暗中爆发、横发横破"的性质。铃贪格为紫微斗数中著名的暴发格局，主突然发财、突然成名，但也主突然破败。须见禄（贪狼化禄或禄存同宫）方为上格；若三方四正更有擎羊、陀罗、化忌，则需防横发横破，先得后失。

- **对宫：** 一宫有贪狼的欲望，对宫有铃星的暗火来冲。该轴线上两宫所主之事，存在"欲望与暗中压力互相激发"的张力。

- **与火贪格的区别：** 火贪格主明面上的突发暴发，来得快去得也快；铃贪格主暗中的突发暴发，来得更隐蔽，但破坏力更持久。

### 铃星 + 火星

- **同宫：** 火星的明火与铃星的暗火同处一宫，该宫所主之事带有"明暗交攻、内外受敌"的性质。既有明面上的突发冲突，又有暗中的慢性压力，精神负担极重。

- **对宫：** 一宫有火星的暴烈，对宫有铃星的阴沉来冲。该轴线上两宫所主之事，存在"明火与暗火互相激发"的张力。

### 铃星 + 紫微

- **同宫：** 紫微的权威与铃星的阴沉同处一宫，该宫所主之事带有"有权威但内心阴沉、多疑、记仇"的性质。紫微因铃星而显得城府深、手段暗，铃星因紫微而有所收敛但本质不改。

- **对宫：** 一宫有紫微的权威，对宫有铃星的阴沉来冲。该轴线上两宫所主之事，存在"权威与暗中压力互相拉扯"的张力。

### 铃星 + 天府

- **同宫：** 天府的稳重守成与铃星的暗火同处一宫，该宫所主之事带有"库被暗蚀"的性质。钱财在不知不觉中慢慢流失，或因暗中压力、焦虑而导致财务决策失误。

- **对宫：** 一宫有天府的稳重，对宫有铃星的阴沉来冲。该轴线上两宫所主之事，存在"守成与暗中消耗互相侵蚀"的张力。

### 铃星 + 巨门

- **同宫：** 巨门的口舌是非与铃星的阴沉同处一宫，该宫所主之事带有"口舌暗中发酵、是非纠缠不休"的性质。不似擎羊+巨门那般尖锐激烈，而是暗中记仇、冷战、背后中伤。

- **对宫：** 一宫有巨门的口舌，对宫有铃星的阴沉来冲。该轴线上两宫所主之事，存在"口舌与暗中压力互相激发"的张力。

### 铃星 + 擎羊

- **同宫：** 擎羊的刚烈与铃星的阴沉同处一宫，该宫所主之事带有"明暗交攻"的性质。既有明面上的冲突刑伤，又有暗中的记仇、冷战。

- **对宫：** 一宫有擎羊的刚烈，对宫有铃星的阴沉来冲。该轴线上两宫所主之事，存在"刚烈与阴沉互相冲击"的张力。

### 铃星 + 陀罗

- **同宫：** 陀罗的纠缠与铃星的阴沉同处一宫，该宫所主之事带有"暗中纠缠、慢性折磨"的性质。中州派称"铃陀主磨炼"，主事情在暗中反复拉扯、拖延，令人精神疲惫。

- **对宫：** 一宫有陀罗的纠缠，对宫有铃星的阴沉来冲。该轴线上两宫所主之事，存在"纠缠与阴沉互相加深"的张力。

### 铃星 + 地空、地劫

- **同宫：** 铃星的阴沉与空劫的虚无同处一宫，该宫所主之事带有"暗中压力落空"的性质。在虚无的事情上暗中焦虑、消耗，精神内耗严重。

- **对宫：** 一宫有铃星的阴沉，对宫有空劫的虚无来冲。该轴线上两宫所主之事，存在"阴沉与虚无互相消解"的张力。

### 铃星 + 文昌、文曲

- **同宫：** 铃星的阴沉与昌曲的文雅同处一宫，该宫所主之事带有"文思阴沉"的性质。有文采但思路偏暗、多疑，写作或表达时带有阴郁、尖锐的风格。入庙则主深思熟虑、有谋略。

- **对宫：** 一宫有铃星的阴沉，对宫有昌曲的文雅来冲。该轴线上两宫所主之事，存在"阴沉与文雅互相影响"的张力。

### 铃星 + 化忌

- **同宫：** 化忌为"引信"，引燃铃星的阴沉之性。该宫所主之事，多暗中压力、精神折磨、记仇、冷战之象。具体应验在哪方面，视所在宫位而定。

- **对宫：** 一宫有铃星的阴沉，对宫有化忌来冲。该轴线上两宫所主之事，存在"阴沉被引燃、暗中压力从外部加剧"的张力。

- **程度差异：** 铃星入庙 + 化忌 + 有吉星制化 → 凶性减轻，主有压力但能转化为动力。铃星落陷 + 化忌 + 无吉星制化 → 凶性难制，主长期精神折磨、暗中灾厄。

## 六、补充说明

- 铃星的凶性可被吉星（如紫微、天府等）制化，但本质不改，只是减轻。

- 铃星入庙时凶性减轻，阴沉可转化为深沉冷静、有谋略；落陷时凶性加重。

- 铃星可以出现在十二宫中的任何一宫，不存在硬性位置限制（与擎羊、陀罗不同）。

- 铃星与火星的关系：两者同为火性煞星，一明一暗。火星主"突发暴烈"，铃星主"慢性阴沉"。两者同宫时形成"明暗交攻"的特殊组合。

- 铃星与陀罗的关系：中州派称"铃陀主磨炼"，两者同宫时主事情在暗中反复拉扯、拖延，令人精神疲惫，但也可转化为坚韧不拔的毅力（入庙时）。

- 铃贪格为紫微斗数中著名的暴发格局，与火贪格并列，主横发横破。成格条件较严格，须见禄方为上格。
