# 01-3-3 火星

## 基本性质

- 火星为六煞星之一，五行属火，化气为杀。

- 主暴烈、突发、急躁、冲动、爆发力、火灾、突发事故。

- 与铃星的区别：火星为明火烧身，主突发的、猛烈的、来去快的灾祸；铃星为暗火灼心，主慢性的、持续的、闷烧的灾祸。

## 庙陷

- **入庙：** 凶性被制，暴烈转化为爆发力、行动力、魄力，主做事雷厉风行、有冲劲。

- **落陷：** 凶性全开，主突发灾祸、暴烈冲动、火灾、意外。

## 火星在十二宫

- **在命宫：** 命主本身性格急躁、冲动、有爆发力，做事雷厉风行但缺乏耐心。

- **在兄弟宫：** 与兄弟/手足/同事关系突发冲突，来得快去得也快。

- **在夫妻宫：** 婚姻中多突发冲突、暴烈争吵，感情来得快去得也快。

- **在子女宫：** 与子女关系突发冲突，或生育过程突发状况。

- **在财帛宫：** 求财过程突发波动，暴起暴落，来得快去得也快。

- **在疾厄宫：** 主突发疾病、急性病、发烧、炎症、火灾伤。

- **在迁移宫：** 在外多突发事故、意外，来得突然。

- **在交友宫：** 与朋友/下属关系突发冲突，易因冲动得罪人。

- **在官禄宫：** 工作中多突发变动，适合需要爆发力的行业（消防、军警、急诊等）。

- **在田宅宫：** 家宅不安，易有火灾、突发变故。

- **在福德宫：** 内心急躁、焦虑，精神压力大，难以平静。

- **在父母宫：** 与父母/长辈关系突发冲突，易因冲动顶撞。

## 火星与其他星曜的组合

> 原则： 以下只写两星同宫或对宫时的组合性质（两星如何交互），不绑定具体宫位。具体应验在哪方面，取决于实际落在哪个宫。
> 
> 

### 火星 + 紫微

- 同宫： 紫微的权威与火星的暴烈同处一宫，该宫所主之事带有"强势但急躁、有魄力但易冲动"的性质。权威因火星而显得霸道，火星因紫微而有所收敛但本质不改。

- 对宫： 一宫有紫微的权威，对宫有火星的暴烈来冲。该轴线上两宫所主之事，存在"权威与暴烈互相冲击"的张力。

### 火星 + 天府

- 同宫： 天府的稳重守成与火星的突发暴烈同处一宫，该宫所主之事带有"守中带变、稳中突发"的性质。天府的库藏之性被火星扰动，有突发损耗或突发变动之象。

- 对宫： 一宫有天府的稳重，对宫有火星的暴烈来冲。该轴线上两宫所主之事，存在"守成与突发互相冲击"的张力。

### 火星 + 贪狼

- 同宫： 贪狼的欲望与火星的暴烈同处一宫，该宫所主之事带有"欲望强烈且急躁、追求刺激"的性质。古诀"火贪格"即指此组合，主突发机遇，但需看整体格局。

- 对宫： 一宫有贪狼的欲望，对宫有火星的暴烈来冲。该轴线上两宫所主之事，存在"欲望与暴烈互相激荡"的张力。

### 火星 + 巨门

- 同宫： 巨门的口舌是非与火星的暴烈同处一宫，该宫所主之事带有"言语暴烈、突发口舌争端"的性质。是非来得突然且激烈。

- 对宫： 一宫有巨门的口舌，对宫有火星的暴烈来冲。该轴线上两宫所主之事，存在"是非与暴烈互相激发"的张力。

### 火星 + 擎羊

- 同宫： 两煞同宫，火星的突发与擎羊的刚锐叠加，该宫所主之事带有"突发且带有伤害性"的性质。凶性叠加，来势凶猛。

- 对宫： 一宫有火星的突发，对宫有擎羊的刚锐来冲。该轴线上两宫所主之事，存在"突发与刚锐互相冲击"的张力。

### 火星 + 陀罗

- 同宫： 火星的突发与陀罗的拖延纠缠同处一宫，该宫所主之事带有"突发之后又纠缠不清"的性质。节奏混乱，既快又拖。

- 对宫： 一宫有火星的突发，对宫有陀罗的纠缠来冲。该轴线上两宫所主之事，存在"突发与拖延互相拉扯"的张力。

### 火星 + 地空、地劫

- 同宫： 火星的暴烈与空劫的虚无同处一宫，该宫所主之事带有"突发但落空、冲动但无果"的性质。爆发力被空劫消解，或突发之事最终成空。

- 对宫： 一宫有火星的暴烈，对宫有空劫的虚无来冲。该轴线上两宫所主之事，存在"暴烈与虚无互相消解"的张力。

### 火星 + 文昌、文曲

- 同宫： 火星的暴烈与昌曲的文雅同处一宫，该宫所主之事带有"刚柔并济但节奏不协调"的性质。有爆发力也有文采，但两者未必和谐。

- 对宫： 一宫有火星的暴烈，对宫有昌曲的文雅来冲。该轴线上两宫所主之事，存在"暴烈与文雅互相冲击"的张力。

### 火星 + 化忌

- 同宫： 化忌为"引信"，引燃火星的暴烈之性。该宫所主之事，多突发灾祸、意外、暴起暴落之象。具体应验在哪方面，视所在宫位而定。

- 对宫： 一宫有火星的暴烈，对宫有化忌来冲。该轴线上两宫所主之事，存在"暴烈被引燃、突发灾祸从外部冲击"的张力。
