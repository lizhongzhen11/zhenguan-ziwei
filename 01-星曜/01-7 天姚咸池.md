# 01-7 天姚咸池

**星等与归属（两星合定位）**：二者同属"次桃花星／杂曜"，与红鸾、天喜并称四大桃花，但性质上同归"野桃花"一类——相对红鸾天喜的"正桃花／喜庆缘"，天姚咸池主的是"激情、风情、肉欲"那一脉，与稳定婚姻没有强连接。级别上流派标注不一（乙级、丙级皆有），不必纠结，关键是优先级：二者权重低于十四主星、四化、六吉六煞，本宫主星强时只作"加味"，主星弱或无主星时其桃花／欲象才上浮为主调。

**共性底色（先合）**：两星都主异性缘强、魅力外显、感情丰富、审美与打扮意识强；都带"桃花本中性"的双刃性——制化得宜是人缘、才艺、魅力、艺术感，制化失宜是淫欲、酒色、烂桃花、因色生事；都属"激情型桃花"，易让人把兴奋感误认成爱情，故多先欲后情、难走入稳定婚约；都遵循同一条铁律——**单见不发动机，须被引动才落实为祸福**（详见适用／失效条件）。共性到此为止，下面是它们各自的本体，**不要混**。

**五行与化气（分写，含分歧标注）**：

- 天姚：五行属癸水（阴水），诸源一致，稳。化气有分歧——古赋多记"化气风流"，因其入庙主"风雅耗禄"，故亦有资料记"破耗／耗"；二者不矛盾，风流是其本性、耗是其耽溺之果，取义时以"风流"为性、以"耗"为果即可，不必二选一。

- 咸池：化气古赋记"桃花"，较一致。五行则分歧大——古赋记阴水，与"凡五行属水皆带桃花"的体系自洽；但另有记阴火、记金者，皆为孤证且与上述体系不合，**存疑**。结论：咸池断事**不以五行为主轴**，以星性本体与组合为主，五行只作背景参考，禁止拿咸池五行去硬推生克吉凶。

**核心主象（分写，这是区分两星的根）**：

- 天姚的本体核心 = **风情 + 交际 + 才艺 + 诱惑**。它管的是"魅力怎么散发、怎么与人周旋"——善察言观色、幽默风趣、有艺术天分（诗词琴棋书画常擅其一）、姿态身材出众、社交吃得开，带一层"会撩、有情调、行事隐秘不欲人知"的复合气质。一句话：天姚是"有术、有才、有风情"的风流。

- 咸池的本体核心 = **肉欲 + 酒色 + 艳丽 + 沉溺**。它管的是"欲望本身的强度、对声色享乐的沉迷"——好打扮而偏艳丽型、感官欲求强、易沉溺酒色财气、感情上偏露水／短暂情缘。一句话：咸池是"重欲、重感官、易沉溺"的淫欲。

- 收束对比：天姚偏"术与魅力"，咸池偏"欲与沉溺"；一个像会交际的才子／尤物，一个像贪享乐的感官派。这是多源里最稳的区分，**以此为主轴**。

**双面性（分写，同一本体的正反，非两件事）**：

- 天姚——正向：才艺、人缘、交际手腕、魅力、艺术天分、姿态优美、博学多能；反向：风流好淫、多疑深沉、心术不正（落陷逢煞时）、因色犯刑、破家荡产、耽酒色而耗禄。

- 咸池——正向：艳丽、吸引力强、审美与打扮、人缘（桃花中性面，会厚重星时转稳，可为魅力／艺术／人际之助）；反向：好色、肉欲、酒色沉溺、露水情缘、烂桃花、因色破败。

- 纪律：正反是同一股"桃花／欲"气在不同条件下的两种显化，禁止把"有才艺"和"好淫"当两条独立结论叠加，也禁止把"艳丽"和"烂桃花"当必然因果。

**旺度表现（只写表现，不写地支，不安星）**：

- 天姚**论庙陷，但只取表现**：庙旺时呈现温文儒雅、博学多才、交际广泛、富贵、姿态优美、异性缘佳，**但庙旺不等于纯吉**——庙旺同时带"风雅耗禄、耽于酒色、性喜声色"，是"才艺富贵"与"耽溺"并存的双面，禁止见庙旺即断纯吉。落陷时呈现多疑、心术不正、风流好淫、喜旁门左道，逢煞则因色犯刑、破家之象偏重。

- 咸池**多不论庙陷**：古赋对咸池只言"入命身财福诸宫主好色"，未分庙陷，多数流派亦不以庙陷论咸池。故咸池的旺度格应记为"本星不以庙陷作判断依据"，其吉凶制化**看会星**而非看旺度——会太阳、禄存、天府等厚重之星则欲望被制而转稳，会煞忌他桃花则沉溺加重。**禁止给咸池硬套庙陷地支**（这正是我天刑那版犯的错，咸池这里直接规避）。

**关联星（分写，只写结构性结论，不写安星法）**：

- 天姚：与天刑在排盘上存在固定照会关系，构成"刑—姚"结构（欲与制的张力，详见天刑条目）；此外与红鸾、天喜、咸池、沐浴等同属桃花群星，为语义关联。注意：刑—姚是结构性照会，不等于同宫，是否成象仍看引动。

- 咸池：**无固定结构性对星**（不像天姚与天刑有安星绑定，不要硬给它配一颗"对星"）；仅与红鸾、天喜、天姚、沐浴等同属桃花群星，作语义关联。其制化关系是"喜会厚重星（太阳、禄存、天府）"，这是会星制化，不是结构对星，别混淆。

**二者区别（合并写的灵魂，列不同点，并明确排雷）**：

- 区别一（本体方向）：天姚 = 风情／交际／才艺／诱惑（魅力如何运作）；咸池 = 肉欲／酒色／艳丽／沉溺（欲望本身多重）。

- 区别二（气质型）：天姚偏"才情型风流"，带艺术性与社交性，行事隐秘而外表能周旋；咸池偏"感官型淫欲"，带消耗性与沉溺性，打扮偏艳丽、欲求偏直接。

- 区别三（旺度可用性）：天姚可借庙陷表现调方向（庙旺才艺富贵兼耽溺、落陷心术淫逸）；咸池不借庙陷，借会星制化（厚重星制之则稳）。

- 区别四（结构关联）：天姚有天刑这一结构照会，咸池没有。

- **排雷（重要）**：不要用"谁主动、谁被动"来区分二者。资料对此说法互相打架（有说咸池主动追求、有说天姚大胆主动），二元标签极易张冠李戴，故**主动／被动不作为区分主轴**；区分一律落在上面的"风情才艺"对"肉欲沉溺"。

**适用条件（淫欲／因色生事"落实"的开关，两星共用，分点）**：

- 须与煞忌同会，或与他桃花（红鸾、天喜、沐浴、廉贞、贪狼、昌曲等）叠见，桃花／淫欲之象才坐实为"因色犯刑、破家、感情混乱、沉迷酒色"。古赋"会恶煞破家败产因色犯刑""天姚与红鸾天喜咸池相会合重淫欲沉迷酒色财气"。

- 天姚落陷放大负面；咸池入命、身、财、福等宫，好色／沉溺之象较显。

- 限年桃花星叠并原局桃花，为桃花事件、激情缘、因色生事类应期的引信（强度上浮条件，归应期判断，本条目不展开断语）。

- 天姚、咸池同见，或其一与他桃花群聚，淫欲／烂桃花之象叠加加重。

**失效条件（不作淫乱／烂桃花／出轨论的刹车，两星共用，分点）**：

- 天姚庙旺会吉（昌曲、华盖、禄存、天马等）→ 转文艺、才艺、名利、交际之正用，**不断淫乱**；古赋"与华盖禄存天马昌曲同会多文艺界人士名利双收"。

- 咸池会太阳、禄存、天府等厚重之星 → 欲望被制而转稳，**不断好色败家**。

- 单见天姚或咸池、无煞无忌、无他桃花叠、本宫主星正而强 → 只主"有魅力／有人缘／有审美／感情丰富／有才艺"的底色或倾向，**不得断淫乱、出轨、烂桃花、一夜情**。

- 本宫整体吉者，桃花星"无妨而添人缘魅力"；本宫整体凶者，桃花星"增其因色之祸"——即桃花星是放大器而非独立发动机，禁止脱离宫位与主星单看天姚咸池定盘。

- 命带天姚或咸池 ≠ 命带烂桃花／必出轨——这是最高频误读，必须刹车。

**强度定位（给 00 全局规则做权重用）**：二者为杂曜，权重低于主星、四化、六吉六煞；作用方式是在"感情／人缘／欲望"维度上加一层色调，或在限年被叠并为应期触发点。其中天姚因带"耗／风流"且与天刑结构照会，在"因色犯刑"类组合里权重上浮；咸池在"肉欲／酒色／露水缘"类象里是核心引信。但单星皆不发动机，须组合引动。

**常见误读**：

- 误读一：见天姚或咸池即断淫乱、出轨、烂桃花、一夜情。纠正：须煞忌或他桃花叠见引动，单见／会吉不落实。

- 误读二：用"主动／被动"区分天姚咸池。纠正：资料打架，不作主轴；区分落在"风情才艺"对"肉欲沉溺"。

- 误读三：天姚庙旺 = 纯吉。纠正：庙旺亦"风雅耗禄、耽于酒色"，是才艺富贵与耽溺并存。

- 误读四：给咸池硬套庙陷地支。纠正：咸池多不论庙陷，制化看会星，旺度不作判断依据。

- 误读五：把天姚或咸池当"正缘／必结婚"。纠正：二者与婚姻无强连接，多主激情／野桃花；正缘喜庆看红鸾天喜。

- 误读六：把天姚五行／咸池五行记死单一答案并据此推生克。纠正：天姚癸水较稳、化气风流／破耗有分歧；咸池五行古赋阴水、另有阴火／金存疑，断事以星性本体与组合为主，不以五行为主轴。

- 误读七：脱离宫位与主星，单凭桃花星下结论。纠正：桃花星是加味与放大，不是发动机。
