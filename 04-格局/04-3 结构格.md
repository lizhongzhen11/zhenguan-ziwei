# 04-3 结构格

> **【AI 执行指令 · 职责边界】**
> 本文件收录"特定宫位/位置结构成格"的要件卡。宫位条件中的星曜亮度**一律以盘面标注为准**；判定流程与分级见《04-0》。

---

## 石中隐玉（巨门坐子午）

- **主星配置**：巨门独坐子宫或午宫。
- **宫位条件**：盘面标注巨门旺庙为要件；子宫通常为正（见巨门档案）。
- **成格效果**：如璞玉藏石，**早年必经磨砺，中年后显露光华**，主厚积薄发、大器晚成、富贵双全。
- **降等与破格**：⚠ 本格大忌——**锋芒太露、走最高峰**：一旦爬到顶点或过于张扬，必遭众人指责反噬，宜保持低调、见好就收。煞忌重 → 破格。

## 月生沧海（太阴坐子；讲义古诀作"水澄桂萼"）

- **主星配置**：太阴坐子宫（**恒与天同同度**）。
- **宫位条件**：**两项并须**——① 盘面标注太阴入庙为要件；② ⚠ **另须合年干与生时：丙、丁年夜生人合格**（讲义古诀"水澄桂萼"之合格条件，本卡从之收紧）。
- **成格效果**：大富大贵，格局极佳（见太阴档案）。
    - **格名之辨**：讲义古诀作"**太阴居子，号水澄桂萼，得清要之职，忠谏之材**"——**与本卡同一格，同格异名，不得并立**；"**清要之职、忠谏之材**"属**古法贵语**，转译为"**岗位清贵、以专业与直言见重**"，**不作具体职位之承诺**。
- **降等与破格**：落陷 → 不以此格论；**年干或生时不合者 → 不作"大富大贵"论，退回《00-1》常轨**。
    - **格内机理（讲义）**：太阴在子天同同度，虽主内向，**当昌曲、化禄、化权、左右同扶，则转化为内才权变**——此即古诀"主任清要之职"之所以然。⚠ 属**成格机理之说明**，**不另立为独立要件**（要件以上列两项为准）。

## 月朗天门（太阴坐亥）

- **主星配置**：太阴坐亥宫。
- **宫位条件**：**两项并须**——① 盘面标注太阴入庙为要件；② ⚠ **另须"见禄"并"有辅佐"：太阴化禄、化权、昌曲、左右、魁钺同度，或禄存同度，且煞忌不见，始合格**（讲义古诀"月朗天门于亥地，进爵封侯"之合格条件，本卡从之收紧）。
- **成格效果**：富贵双全，具"月光"般的柔和魅力（见太阴档案）。
    - ⚠ "**进爵封侯**"属**古法贵语**——转译为"**格局高位、权重任重**"，**不作具体职位与品级之承诺**。
- **降等与破格**：**不合"见禄＋辅佐"条件者 → 不作本格论，降等退回《00-1》常轨**；煞星干扰 → 降等；落陷 → 不以此格论。

## 明珠出海（命坐未，日卯月亥来朝）

- **主星配置**：命坐未宫，太阳在卯、太阴在亥二宫来朝（双旺朝命）。
- **宫位条件**：日、月**皆盘面标注庙旺**为要件。
- **成格效果**：如明珠出海，光华渐显，主富贵清显、声名渐著。
- **降等与破格**：日月其一失辉 → 降等；命宫煞忌重 → 破格。
- **辨析**：与"月朗天门"不同——彼为太阴坐亥**守命**，此为日月**朝命**；与"日照雷门"共享结构，可并参。

## 日照雷门（太阳坐卯）

- **主星配置**：太阳坐卯宫。
- **宫位条件**：盘面标注太阳庙旺为要件。
- **成格效果**：贵显，光明磊落，声名远播；利公职、教育、传播。
- **降等与破格**：煞忌重 → 降等。

## 英星入庙（破军坐子午）

- **主星配置**：破军坐子宫或午宫。
- **宫位条件**：盘面标注破军入庙为要件。
- **成格效果**：地位崇高，开创有成（见破军档案）。
- **降等与破格**：无禄无吉 → 只破不立，降等。

## 雄宿朝垣（又名雄宿乾元格；廉贞坐未或坐申）

- **主星配置**：**未、申二宫两形并列，不分正次**——**未宫**为廉贞与**七杀同度**（"廉杀同宫"）；**申宫**为廉贞**独坐**（对宫恒为贪狼，七杀在午）。⚠ 廉贞与七杀**只同度于丑、未**，本格**只取未宫**——**丑宫纵见吉，亦不以本格论**；廉贞独坐**只在寅、申**，本格**只取申宫**——**寅宫刚烈无制，亦不入本格**。
- **宫位条件**：⚠ **核心要件为"见吉无煞"**——须**有吉星会照**，且**不遇四煞（擎羊、陀罗、火星、铃星）、空劫、刑耗冲破**；廉贞**另须盘面标注庙旺**。**无"吉星会照"者，纵无煞亦不入本格**（依《04-0》二之 3"辅煞条件"）。
- **成格效果**：**成器之象，富贵声扬**——廉贞之**阴火**与七杀之**阴金**相制为用，"好似荒山矿石经火煅炼后，乃成极名贵的原料"。主**大器晚成、掌权、能成一方之主**。
- **降等与破格**：煞忌冲破 → **不论格、退回《00-1》常轨**，以官非、破格断；见吉辅与禄 → 成格更确。
- **辨析**：
    - ⚠ **名近而实异者**——「**府相朝垣**」（见《04-2》）与「**双禄朝垣**」（见《01-4 禄存》）**与本格不是同一格**，仅共享"朝垣"二字，**不得互相援引**。
    - ⚠ **"七杀在午"是安星定式的等价重述，不是额外要件**——廉贞坐申 ⇒ 七杀**恒在午**（本助手实测 358 例零例外），且**午与申非三合**（申之三合为子、辰）；午宫在此为**夫妻宫**位，**不得写作"三合午宫七杀"**。
    - ⚠ 未宫另与「**廉贞清白格**」**宫位重叠而要件不同**（重"**禄**"者为清白格、重"**吉而无煞**"者为本格），**二者可并存**（详见《01-1-6 廉贞星》模块三工艺注②，该格**尚未立卡**）。

## 极向离明（紫微坐午）

- **主星配置**：紫微独坐午宫守命（"极"＝紫微，"离明"＝午位）。
- **宫位条件**：盘面标注紫微入庙；**无刑忌**（不见擎羊、化忌同宫或冲）。
- **成格效果**：大贵，公卿之命，位高权重。古诀"紫微居午无刑忌，甲己丁人至公卿"。
- **降等与破格**：见擎羊/化忌 → 格局降低，降等；煞忌重 → 破格。

## 火贪格 / 铃贪格

- **主星配置**：贪狼与火星（火贪）或铃星（铃贪）同宫或会照。
- **宫位条件**：**以引擎 `star.brightnessText` 标注贪狼庙旺为要**（**禁止凭记忆推定**；库内旧文所称"盘面标注"即引擎输出，二者同义，见《SKILL.md》加载纪律第 4 条）。
- **上格要件（王亭之）**：**须"与武曲相干"**——即 **① 贪狼与火铃同度，而对宫为武曲**（**辰、戌二宫**：贪狼独坐、对宫恒为武曲），或 **② 武曲贪狼同度而见火铃**（**丑、未二宫**）。**因武曲是财星，故火贪、铃贪格喜见**。**不具此者格仍在，然只作横发论、不作"上格"论。**
- **成格之次第（陆斌兆）**：**辰、戌为上格 ＞ 丑、未为次格 ＞ 其他宫位更次之**——⚠ **与上条同一分界**（**陆氏举其宫**：辰戌者对宫有武曲、丑未者与武曲同度；**王氏举其理**：须与武曲相干），**两说互补、并不冲突**。
- **成格效果**：**横发**——突发横财、暴富、意外之喜；亦主突发之机遇。**本格有"富""贵"两层**：**会辅佐诸曜者兼主贵**；不具辅佐者只作横发论。古诀三则（王亭之引古人）："**贪狼火铃四墓宫，豪富家资侯伯贵**""**贪狼火星居庙旺，名振诸邦**""**贪铃并守，将相之名**"——⚠ 俱属**古法贵语**，转译为"**于所属领域居前列、或得权重之位**"，**不作品级、职位与财数之承诺**。
- **降等与破格**：贪狼落陷或煞忌过重 → 横发横破，得之不久，甚至因暴发招祸；化忌同宫 → 破格。
- **辨析**：
    - ⚠ 与"**马头带箭**"同属**以煞成格**一类（《04-0》二之 3），**要件各从其卡，不得互相援用**。
    - ⚠ **"须与武曲相干"之要件以本卡所载为准**；《01-3-4 铃星》另载铃贪"**须见禄（贪狼化禄或禄存同宫）方为上格**"一说——**两说义理相通而未统一，并存核之，不得只据其一即许"上格"**（**待裁**）。
    - ⚠ "**贪狼以辰戌丑未为庙、子午为旺**"系讲义所传之**取象框架**，**不构成取数依据**；判时一律以引擎 `brightnessText` 为准（见《01-1-9 贪狼星》模块五）。

## 日月并明（日辰月戌，日月同辉）

- **主星配置**：太阳居辰、太阴居戌，分守命宫/身宫或命宫三方；⚠ 一说日月分居丑未线皆旺亦论。本库以"日辰月戌皆盘面庙旺"为正格。
- **宫位条件**：日月**皆盘面标注庙旺**为死条件；一旺一陷即不成格。
- **成格效果**：日月同辉，富贵双全、少年得志、父母俱荣。
- **降等与破格**：单星失辉 → 降等；煞忌冲破 → 破格。
- **辨析**：⚠ 坊本以本格（日辰月戌）与"**日月反背**"（日戌月辰，双陷）**互为镜像**，**本库不采该口径**——本派之"日月反背"为**太阳在亥／太阴在卯**（见下卡），与本格**不同组、不同源，不得互相援用**。

## 日月反背（太阳在亥／太阴在卯）

- **主星配置**：**太阳在亥、太阴在卯**（日月恒相对或同度，亥卯为其一组）。
- **口径说明（⚠ 本库采本派讲义口径）**：**坊本多以日月在辰戌为反背，本库不采**——本派以**太阳在亥／太阴在卯**为"日月反背"，与《01-1-3 太阳星》模块五"反背之辨"、《01-1-8 太阴星》模块五"与太阳之对位"条同载。
- **成格效果**：⚠ **"反背"之名不主凶**——太阳在亥虽落陷、太阴在卯虽失垣，然**二宫见辅佐（昌曲／辅弼／魁钺／禄存）及吉化者，反成大富大贵之格，且年轻即有成就，于斗数中属上格**（讲义明言）。**本格属上格，不是"否极泰来"之格。**
- **降等与破格**：不见辅佐吉化者，**不作"大富大贵"之论**，退回《00-1》五步判定（格之是否成立，**以引擎 `brightnessText` 与辅佐计数为准**，不得凭记忆推定）；见煞忌冲破 → 破格。
- **辨析**：
    - ⚠ 与"**天同反背**"（见下节）**同名不同格、不同源，不得互相援用**——彼之要件在**丁年四化齐会**（天同在戌化权，对宫巨门化忌），与本格"太阳亥／太阴卯"无关。
    - ⚠ **坊本"日戌月辰双失辉"之说（旧作"早年极其艰辛、中年后大器晚成"之否极泰来格）非本派之"日月反背"**——该项之格名与吉凶判法**本库不采**：遇"太阳在戌＋太阴在辰"之结构，**不得以"日月反背"名之，亦不得据"反背"二字作否极泰来之断**，一律按《00-1》常轨判定。
    - ⚠ "**否极泰来**"另有所指——天同在**辰宫**化忌而会到禄存／化禄者，陆氏亦称"**否极泰来之象**"（**未立格**，见《01-1-5 天同星》），与该星在**戌宫**之"反背"格亦不同源。**三者（本格／天同反背／天同辰宫否极泰来）判时各依其要件，不得据词混断。**

## 泛水桃花（贪狼坐亥子）

- **主星配置**：贪狼坐亥宫或子宫。
- **宫位条件**：⚠ 有派以凶论、有派以旺论，**以盘面标注及辅佐综合判定**。
- **成格效果**：桃花泛滥，多情多欲，交际生财；见吉主风月才子，见煞忌主因色惹祸。
- **降等与破格**：逢空劫 → 转向修行、艺术、宗教，反主超脱（见贪狼档案）。

## 风流彩杖（贪狼坐寅，陀罗同度）

- **主星配置**：贪狼坐**寅宫**（**对宫恒为廉贞**——安星定式；王亭之："贪狼在寅宫，对宫为廉贞"），与**陀罗同度**。
- **宫位条件**：**以陀罗同度为准**（陆斌兆、王亭之两说一致）；古诀"**贪狼陀罗在寅宫，号曰风流彩杖**"。
- **成格效果**：主**贪色，或因色（桃色之事）遭灾**——⚠ 今取"**因情色之事越界而生纠葛、致受累**"之象；**属涉己品性与风险取象，非对命主之定性**（出口依《05-4》§四.7 三要件）。
- **变格**：**寅宫贪狼会擎羊、天刑**者，古法主"**牢狱之灾**"——**王亭之明言此属"风流彩杖之变格"**。⚠ **天刑属杂曜、不入《00-4》计分，仅作条件**；"牢狱"属**官非类**，出口只作"**宜守正合规、留意因交际或情色而生之法律风险**"式风险提示（《05-4》§四.1、2），**不直断、不给时间点**。
- **降等与破格**：⚠ **见禄存同度、或见化禄者，其象得解**——王亭之："寅宫……**除非禄存同度或化禄，否则难有作为**"；**不见禄而煞刑会合者**只作"处境较重、易生是非"论；**得辅佐吉曜扶**者，可转为**才艺、公关之能**（见《01-1-9 贪狼星》模块三）。
- **辨析**：
    - ⚠ 与"**泛水桃花**"（上卡）**同属贪狼遇羊陀之桃花凶格，然落点不同**：泛水桃花系于**亥、子**，本格系于**寅宫**（四马地、对拱廉贞）。**二格各依其要件，不得混断、不得叠加。**
    - ⚠ **申宫不作本格**——王亭之明言"**与廉贞相对之时，寅宫不及申宫**"，本格要件系于**寅宫**，**申宫无此格名**（申宫贪狼之吉凶另有其论，见《01-1-9 贪狼星》模块六命宫条）。
    - ⚠ 与"**马头带箭**"（见下卡）虽**同涉"羊陀之落于特定宫位"之机制**，然**彼为吉格（煞反成其器）、此属凶格，不得互相援用**。

## 梁马飘荡（天梁坐巳亥）

- **主星配置**：天梁坐巳宫或亥宫。
- **宫位条件**：盘面标注天梁落陷为要件；四马地环境（《02-1》附一）加重飘荡。
- **成格效果**：一生飘荡不定、多变动奔波，宜流动行业；落陷则解厄之力弱。
- **降等与破格**：见吉星扶持 → 飘荡中有成，降凶；煞忌重 → 飘荡无成，以凶断。

## 马头带箭（天同坐午，擎羊同度）

- **主星配置**：天同坐午宫，与擎羊同度。⚠ 天同坐午**恒与太阴同度**（安星定式），故本格实为"天同太阴在午＋擎羊同度"。
- **宫位条件**：**以煞成格**——擎羊落午宫**唯年干为丙或戊时成立**（该年禄存必坐巳）。**须盘面实见擎羊在午**，非丙／戊年者不论。
- **成格效果**："**威镇边疆**"，主**为国效劳、掌握兵符大权**，为立功疆场之大将；**主经历艰难而有成**（陆氏"反主为国效劳……立功战场的大将"，王氏"斗数中的大格"）。属"**煞曜反成其器**"之特殊机制。
- **降等与破格**：非丙／戊年擎羊不落午 → **不成格**，退回《00-1》常轨；同度太阴落陷、再叠其余煞忌 → 只作辛劳奔波，不成大格；见吉星辅佐 → 成格更确。
- **辨析**：与"火贪／铃贪"同属**以煞成格**一类（《04-0》二之 3）。**不得见天同在午即断马头带箭**，须先核年干与盘面擎羊实况；又，**子宫**之天同太阴**不须擎羊激发**（同度太阴入庙），走"**喜见辅佐诸曜、主清贵**"一路，**两宫不得混断**。

## 天同反背（天同坐戌，丁年四化齐会）

- **主星配置**：天同坐戌宫。
- **宫位条件**：天同于戌宫**独坐**，**对宫恒为巨门**（安星定式）；"**反背**"之名即取自**天同在戌**。
- **四化条件**：**本格核心要件**——**年干须为丁**（丁干四化＝太阴禄、天同权、天机科、巨门忌）。成格须**四化齐会**：**天同在戌宫化权**＋会**寅宫太阴化禄、天机化科**＋会**辰宫巨门化忌**。**缺一不可**。
- **成格效果**：古诀"**天同戌宫为反背，丁人化吉主大贵**"。机理——天同之**化权能平稳其情绪**，**解巨门之阴暗**，而**巨门之化忌反成为天同的激发力**，由是转化为良格；主**先经艰危而后发、大器晚成**。
- **降等与破格**："**如无四化齐会，则不成'反背'之格**"——缺任一化 → **不成格**，退回常轨（**不得径以"戌宫"二字成格**）；成格后再见煞忌冲破 → 破格。
- **结构说明（安星事实，非巧合）**：天同在戌 ⇒ 紫微恒在卯 ⇒ **天机、太阴恒在寅，巨门恒在辰**；而丁干四化之落点恰分居戌宫之**三合**（寅）与**对宫**（辰），故**丁年生人天同在戌，四化齐会必然成立**。
- **辨析**：⚠ 与"**日月反背**"（**太阳在亥／太阴在卯**，见上卡）**同名不同格、不同源，不得互相援用**——彼为日月一对之结构格，本格要件则**在丁年四化齐会**，且天同于此恰为**化权**而非化忌。⚠ 亦与**天同化忌**无涉：本格之化忌在**巨门（丁干）**，**不得以"庚年天同化忌坐戌"当反背格**。⚠ 坊本另有以"日戌月辰双陷"名"日月反背"之说，**本库不采**（详见上卡辨析）。
