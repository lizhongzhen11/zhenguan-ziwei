# 04-0 格局总纲

> **【AI 执行指令 · 职责边界】**
> 本文件是格局判定的总法：成格通则、分级规则、未收录格局的处理、检索流程。
> 各格要件卡见 04-1～04-5；格局与吉凶加减的关系见《00-1》第二步之 5（格局例外优先）；煞格成立时的污染度计分仍走《00-4》。

---

## 一、什么是格局

格局 = 特定星曜配置形成的**结构性主题**。成格则该宫（或全盘）按格局断，**不再适用单星加减分**（《00-1》五步之 5：格局例外优先）。
不成格（要件不齐）则退回《00-1》五步常轨判定，**禁止"见格名即断"**。

## 二、成格通则（正格四要件）

一格之成立，通常核四类要件（各格要件卡逐项列明）：

1. **主星配置**：指定主星同宫或会照。
2. **宫位/结构条件**：特定宫位、夹宫、对宫结构（结构格才有）。**星曜亮度一律以盘面标注为准**。
3. **辅煞条件**：正格多要求"无煞冲破"（不见羊陀火铃化忌同宫或冲）；少数格局**以煞成格**（火贪、铃贪），从其专属要件。
4. **四化条件**：指定四化同宫或会照（四化格才有）。

## 三、分级：正格 / 变格 / 破格

| 级别 | 条件 | 断法 |
|---|---|---|
| **正格** | 要件全部满足 | 按格局断语直断，档位锦绣前程/前景可期 |
| **变格（降等）** | 缺次要要件（如缺辅星朝拱、亮度不足） | 格存而力减，断语降等留余地（"有成格之势，惜条件未纯"） |
| **破格（假格）** | 见煞忌冲破（羊陀火铃化忌同宫或冲宫），或触该格专属破戒 | 不论格，退回常轨判定；煞重者反以凶断 |

> 各格专属破格条件优先于本通则（如"府相朝垣"忌空库、"石中隐玉"忌锋芒太露之应期）。

## 四、未收录格局的处理

04 层只收录核心格局。遇到档案或古籍提到、但 04-1～04-5 未收录的格局名：
1. 按第二节通则**拆解其要件**（主星组合？宫位？辅煞？四化？）；
2. 要件齐全 → 参照同类已收录格局断；
3. 要件不齐或无法拆解 → **不论格**，退回《00-1》常轨；
4. 禁止仅凭格局名称望文生义下断。

## 五、检索流程（本命总论 Step 1 调用）

1. **组合线索**：命宫（及身宫）主星组合 → 查《04-1》。
2. **会照线索**：命宫三方四正会到的星群 → 查《04-2》；会到的四化 → 查《04-4》。
3. **结构线索**：命宫主星是否落于其"专属宫位"、有无夹宫结构 → 查《04-3》。
4. **破格线索**：夹宫凶夹、煞忌同蹲 → 查《04-5》。
5. 每命中一个候选格 → 核要件卡 → 定正格/变格/破格 → 记入总断。
6. 一人可兼多格：正格与破格并存时，**破格优先报**（"成格有瑕"比"不成格"更要紧）。

## 六、与其他层的关系

- 格局判定**先于**辅佐/污染加减（例外覆盖），但**亮度、煞忌计分、四化碰撞**分别调《00-2》《00-4》《03-3》，本层不重复计算。
- 星曜档案（01 层）中散见的格局表述（如太阴档案"月生沧海"、贪狼档案"火贪暴发"）为个性语境，**要件以本层要件卡为准**。
