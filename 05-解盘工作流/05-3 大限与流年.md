# 05-3 大限与流年

> **【AI 执行指令】**
> 前置条件：《05-1》排盘建档完成且用户已确认、《05-2》本命总论完成。
> 原则：**问大限必有大限盘，问流年必有大限盘＋流年盘**；盘面数据一律由贞观紫微引擎 CLI 取 JSON，**禁止识图、禁止依赖文墨天机、禁止凭生辰八字自行推算**。识别结果追加进同一份记录 md。
> **node 可用性**：本文件所有 `node engine-cli.mjs` 调用一律按《05-0》第一节做跨平台查找并替换为 `"$NODE_BIN" engine-cli.mjs`，禁止裸用 `node`。
>
> **【最高原则：数据缺位即中断】** 解读所需的任何一层盘（本命/大限/流年）在记录 md 中缺失时，先调引擎补排、再解读。**坚决不排盘**（指不自行推算）——一切盘面数据只来自引擎 CLI。
>
> **【校验前置（取代复述确认关）】** 大限/流年盘调出后，先过《05-0》校验三规——①输出 `longitude` 与 `_offsetMin` 与本命建档一致；②大限 `daxianPalaceBranch` 与 `chart.json` 的 `daXians[idx].palaceBranch` 一致；③大限/流年四化与"层宫天干→《03-1》四化表"对得上：
> - **三项全过** → 把盘要素（大限命宫干支/四化/叠宫/动态星）**完整列出**，附一句"以上与你所排如有出入，指出哪一项我重排"，**直接进入解读**——不再等用户确认；
> - **任一不过** → 强制中断排查，禁止解读；排查期间每轮收尾提醒，直到修复。
>
> 为何不再设确认关：确认关的本意是防错盘，而校验三规已能内部发现错盘（实证：错盘的四化也能自洽，光看输出看不出，但 palaceBranch 反查一抓一个准）；且两例实盘测试行为相反（严守→悬置烂尾零解读；绕过→流程顺畅），证明确认关守不住、也不必要。**本命盘的生辰确认关（《05-1》）不在此列，仍然强制。**
>
> **【悬置不丢】** 处于待办态的事项——核验未过待排查的盘、用户明确要求复核的盘、被中断未答的提问——其后**每一轮回复的收尾**必须带一句悬置提醒（如"第 X 大限盘校验未过仍在排查""你此前问的 XX 还未答"），直到办结或用户明确放弃；用户插话先处理，**处理完毕后必须主动回到悬置事项**。实证教训："启动了没完成"与"完全没启动"同罪。

## 〇、 综合性提问的处理（一生运势、未来几年、应期类）

用户问"一生运势""未来几年如何""什么时候结婚/发财"等综合或应期类问题：

1. **先核对记录 md**：该问题涉及的大限/流年盘记录是否齐全。
2. **缺失 → 补排**：明确列出缺哪几张盘（第 X 大限、XXXX 流年），调引擎逐一补排（见下方调用方式）→ 按顶部「校验前置」过三规 → 列全要素后直接解读。
3. **一生总览**：若需全部大限，先告知用户所需盘数，并建议可改为先问当前大限或指定流年，分批进行。
4. 应期判断依据：三层读法（《02-4》）＋限年四化触发（《03-3》）；**禁止无盘估应期**。**象期分离**（《05-2》Step 5）：本命层只出"象"不出"期"——专项分析中凡拟出含时间性之结论（早/迟/应期），一律先回本文件调限运盘再下判。
5. **选项式确认（范围未明时，先算再选）**：提问含时间指向但未指明哪段时，**AI 先自行算出范围，再给 2~3 个候选让用户挑**（规格同《05-2》Step 5「未指定年份时的默认规则」），例如"【当前大限（虚岁 XX–XX，公历 XXXX–XXXX）】／【某个具体年份】"。用户已在提问中点明范围者（"明年""这十年""结婚前"）**直接采信并明示范围，不再多问一步**。**两条禁令**：①禁止把"你想看哪几年"原样抛回；②禁止不给候选、只笼统问"你想看什么时间范围"——命主通常不知自己各大限起讫，两种问法都只能得到干瞪眼。**本步只对齐范围，不改变"范围一旦确认即调盘→校验三规→列全要素直接解读"的既有链路**（校验前置，不再设确认关）。

## 一、大限分析

### 1.1 调引擎取大限 JSON

用户问大限时：调引擎取该大限 JSON（除非记录 md「五、大限记录」中已有该大限）。

先按用户表述匹配 idx（daXians 按 startAge 升序，idx 从0起）：
- "35-44岁大限" → 匹配 `startAge<=35 && endAge>=44` 的 idx
- "第4大限" → idx=3
- "当前大限" → 引擎输出的 `currentDaXianIndex`

```bash
node ziwei-chart/engine-cli.mjs <生辰参数> --daxian <idx>
```

输出含：大限命宫/干支、大限四化（禄/权/科/忌 + 落宫 overlay）、大限12宫叠本命关系。

### 1.2 大限盘要素（从 JSON 提取）

1. 大限命宫位置与干支（**大限天干**——大限四化的源头，JSON 的 `daxianStem`）。
2. **大限四化**：JSON 的 `daxianSiHua.transforms`（禄/权/科/忌 → 星曜 → 落宫 overlay）。对照《03-1》核对（防 agent 记错四化表）。
3. **大限动态星**（运羊/运陀/运禄/运马/运昌/运曲/运魁/运钺/运鸾/运喜，v1.1.0 全量）：JSON 的 `daxianStars`（12 项，按本命宫序，每项含 `natalBranch`/`natalPalaceName`/`scopePalaceName`（该本命宫在大限盘中的宫名）/`stars[{name,base}]`，`base` 为本命对应星名如"擎羊"）。**为 null 时**表示引擎未取到（horoscope 不可用或层干支校验不符），按无动态星处理并告知用户，不得自行推算。
   - **计分**：运羊/运陀按《00-4》二之二节减半计入污染度；运禄/运昌/运曲/运魁/运钺按《00-1》动态辅佐计数（须标注来源）；运马、运鸾/运喜不计分。
   - **取象**：运煞主该十年的阻碍/刑伤应期所在（落哪个大限宫，哪个领域有摩擦）；运禄主该十年的财禄机会点；运昌/运曲主该十年文书、科名、才艺之助（入大限官禄/命宫尤显）；运魁/运钺主该十年贵人提携（入大限迁移/官禄尤显）；运马主变动、迁动之象（与叠宫联读：运马入大限迁移/命宫，十年多动）。
   - **运鸾/运喜（婚恋/喜庆应期）**：⚠ **同层恒不可落命/夫/福**——运鸾支＝(3−大限命宫支) mod 12，与大限命宫支**奇偶恒相反**，故运鸾/运喜**永远落不到大限命宫、夫妻宫、福德宫**（同层偶数位宫＝命/夫/财/迁/官/福皆落不到），只可能落大限的**兄弟/子女/疾厄/交友/田宅/父母**六宫（原理见《01-6》第八节"同层落宫约束"）。另注：鸾与喜**恒处对宫、绝无同宫之可能**（《01-6》第三节），故"成对"指一二星分居对宫。本层有效读法：①运鸾/运喜落**本命**命宫/夫妻宫/子女宫（跨层，无奇偶约束）；②运鸾/运喜落**大限子女宫**（同层唯一可用的婚恋宫）；③运鸾/运喜与**流年**鸾喜叠会（跨层）。成对力量为一，单见减半，只作"有机缘"参考。须与大限四化联读——大限化禄/化科入**本命**夫妻宫或**大限子女宫**时，婚恋应期信号最强；逢运煞同宫则过程多磨，措辞落到"有机缘但需经营"，不得直断"必婚"。**禁止再写"运鸾入大限夫妻宫/大限命宫"式断语**（恒不可触发）。
4. **叠宫关系**：JSON 的 `overlay[12]`，每宫含 `daxianPalaceName` + `natalBranch` + `natalPalaceName` + `natalStars[]`。
   - **两个宫名分工不得混用**：`daxianPalaceName`（大限盘宫名）用于**定档**（大限盘内三方四正与计分范围）；`natalPalaceName`（本命盘宫名）用于**定作用面**（跨层坐/冲/照清单）。详见 §1.3 第 2～4 步。
5. 当前流年位于大限盘何宫（若用户已提供流年）。

识别结果写入记录 md「五、大限记录」，按「校验前置」过三规后解读。

### 1.3 大限解读

1. **定主题**：大限命宫叠本命何宫 → 该十年主题（《02-4》三步走）。
2. **定三方四正（先取范围，禁凭记忆）**：大限专项宫的三方四正，**一律查《02-2》第一节"三方四正映射表"**——在该宫行上读取"对宫 / 三合宫1 / 三合宫2"，与本宫合成 {本宫, 对宫, 三合宫1, 三合宫2} 四宫，即本步的计分范围；宫名一律用**大限盘宫名**，不得与本命盘同名宫混淆。**禁止凭记忆填写、禁止脑内估算后直接使用**（若改用 +6/+4/+8 推导，须落笔逐宫写出四宫名核对；取法口径同《05-2》Step 2 第 0 步——错一宫则整盘计分全错）。该范围各宫的星曜取 JSON `overlay[]` 的 `natalStars`。
3. **吉凶计分（视角一·大限盘内·定档）**：
   - 煞忌按《00-4》计（**论大限时加计大限忌**）；吉曜按《00-1》第一节动态辅佐计（本命辅佐＋运辅佐，须标注来源）；四化修正按《00-1》第二节第 4 步。
   - **计分范围＝第 2 步所定"大限盘三方四正"**（本节首句"大限盘要素的计分只看大限盘三方四正"即指此）——**不得改以本命宫位为计分范围**；同一批地支位置在本命盘上的宫名另由 `overlay[].natalPalaceName` 反查，用于下一步。
   - **三层四化汇集（逐条列出）**：落在上述三方四正内的 **生年四化（底色）＋大限四化（过程）** 须逐条列明，不得只列大限四化；**同坐一宫**的读法调《02-4》§五之五（**不抵消、是叠加**）；碰撞定性分两路——**同层多化**查《03-3》第一节（该表覆盖同宫 / 对宫 / 三合照，**落于三合者烈度较轻、作牵引读**；**只定性、不入档位**），**生年 × 大限叠**查《03-3》第四节（**限同宫**，双禄交临 / 双忌交临 / 禄解忌 / 忌破禄）；层级高低调《03-3》第二节（生年①>大限②>流年③>宫位自化④）。
   - **宫干四化（飞星）只作补充验证**（《03-3》第五节）：只用于佐证定语与观象三层，**不入本限档位计分**。叠宫位置的宫干**不分层、只有一个**（即本命该地支宫的宫干，《02-4》§五之一），故**不存在"大限各宫的宫干"，禁止自行推大限十二宫干**（引擎亦不输出该数据）。
   - **结构检索（虚破孤刑·独立一票）**：调《00-1》第二节第 6 条——上列均为**加减计分**，而"**虚／破／孤／刑**"属**结构性病征、在加减法里无权重**，故须**单独检索**：命中即**压档（至少半档）并写入定语**，**不受前几项计分覆盖**。检索范围为**大限盘三方四正**（宫名用大限盘宫名），四类结构的定义与"通则非穷举清单"操作口径同《05-2》Step 2 第 6 步。
4. **会照清单（视角二·本命盘·定作用面，强制逐项枚举，枚举完方可进入下一步）**：大限四化/动态星是从"外面"作用于本命盘的——站在**本命盘**视角，**坐、冲、照三档都要列，不得只列坐冲**（"照"是《00-4》独立 0.5 权重的档次，漏照即漏掉整档）。**枚举直接查 JSON 的 `branchLookup[12]`**（按 natalBranch 定序，含四化落宫 `scopeSiHua`/`scopePalaceName` 与动态星落宫 `dynStars`）；**冲宫 = 该 natalBranch ±6，照宫 = ±4/±8，禁止手工重建映射**：
   - 大限化忌**坐/冲/照**本命何宫 → 该本命领域十年受压／被冲动而多波折／被牵动；
   - 大限化禄/权/科**坐/冲/照**本命何宫 → 该本命领域十年得助（禄=资源、权=主导、科=声名）；
   - 运羊/运陀**坐/冲/照**本命何宫 → 该本命领域为十年摩擦应期点；
   - **本命命宫/身宫/财帛/官禄/疾厄被坐、冲、照时，必须写进定语。**
5. **大限专项**（用户问大限婚姻/财富等）：
   - **看大限对应宫位**（如大限夫妻宫、大限财帛宫），并按第 2～4 步走完"三方四正定范围 → 大限盘内定档 → 本命盘会照定作用面"。
   - **回查本命底色（强制）**：必须回查记录 md「三、本命总论」中**该本命宫的档位与定语**作底色——本命＝底色、大限＝过程（《02-4》§三/§五之五）；大限专项结论在该本命宫档位的势能区间内展开，**不得越过本命底色单论**（大限财帛宫配本命财帛宫、大限官禄宫配本命官禄宫，余此类推）。
   - **叠宫互涉**：大限专项宫叠本命何宫 → 两主题绑定（《02-4》§四，如"大限财帛宫叠本命官禄宫"＝这十年财务主题与本命事业底盘纠缠）。**叠宫只定"什么事跟什么事绑在一起"，不定因果方向**——是"此影响彼"还是"彼影响此"，须由四化飞入/飞出/自化定（《02-4》§五之二/三/四）；**无四化指向时只写"两事纠缠"，不下因果**。
   - **不得套用同层联动表**：本步是跨层读法（《02-4》§八"叠宫＝纵向"）；《02-3》对宫互看主题表属同层横向，不可套用（如财帛的对宫是福德，财与官的同层关联走三合"命财官三角＝立身格局"）。
6. **结论按《00-1》四之三走"观象三层"**：大限观象的定位是**十年结构性倾向**（过程、底色、范围）。三层依次写足——**能量**（这十年是一股什么性质的力、来源四化与动态星，须标象源）→ **宫位**（该十年主题落在哪一宫、该宫主何事）→ **含义**（这股能量在这十年落此宫的象义倾向；好的一面与需留意的一面都写，**面向不懂命理的普通人须写足写通俗**，低位档必留转机）。末尾固定接**留意声明**：具体应验成哪件事因人因时而异，本报告不推定（大限之能量流动歧义比本命更大，含义层尤须讲透）。**禁止对大限下"会变成哪件具体事"的推定**。含义层的转译方向按情境档案校准，且大限须比对命主当前所处阶段——同一能量的落点随人生阶段而变（例：官禄宫之象，学生命主含义层落在学业方向，已退休命主改从福德/休闲角度落）。
   - **应期/主题定位类提问须先按主题线筛**：大限层同理——先看该提问主题落在哪条线（**大限专项宫及其叠宫关系**），再在这条线上展开观象三层；**不得仅按四化力度排序**（同 §2.3 第 8 步两级过滤的原则）。
7. 结论写入记录 md「五」。

## 二、流年分析

### 2.1 调引擎取流年 JSON

用户问流年时：**先确认所属大限**（流年必落在某大限内），再调引擎取大限+流年 JSON（除非记录 md 中已有）。

```bash
# 大限 + 流年一并取
node ziwei-chart/engine-cli.mjs <生辰参数> --daxian <idx> --liunian <公历年>
```

输出含：大限盘（同上）+ 流年盘（流年干支/命宫/四化/叠宫）。

若用户不知所属大限 → 按出生年+流年公历年反推虚岁 → 找覆盖该虚岁的大限 idx。

### 2.2 流年盘要素（从 JSON 提取）

1. 流年干支（JSON 的 `ganzhi`）、流年命宫位置（`liunianPalaceBranch`）。
2. **流年四化**：JSON 的 `liunianSiHua.transforms`（对照《03-1》核对）。
3. **流年动态星**（流羊/流陀/流禄/流马/流昌/流曲/流魁/流钺/流鸾/流喜，v1.1.0 全量）：JSON 的 `liunianStars`（结构同 `daxianStars`，`scopePalaceName` 为流年盘宫名）。**为 null 时**按无动态星处理，不得自行推算。
   - **计分（三层并计，须分层标注来源）**：论流年为**触发层**，《00-1》§一 明定"论流年计**本命辅佐＋运辅佐＋流辅佐**"——
     - **煞忌**：生年忌＋大限忌＋流年忌**三层并计**（《00-4》）；流羊/流陀按《00-4》二之二节**再减半**计入（流煞为三层中权重最低）。
     - **辅佐**：本命辅佐（左右/昌曲/魁钺/禄存）＋**运辅佐（运昌/运曲/运魁/运钺/运禄）**＋流辅佐（流昌/流曲/流魁/流钺/流禄）**三层同计**，按《00-1》第一节动态辅佐规则（单见 1、成对 2、禄 1）；**只列流曜而漏运曜即为漏计**。
     - **不计分**：运马/流马（只作动向参考）、运鸾/运喜/流鸾/流喜（只作婚恋应期取象）。
   - **取象**：流煞主该年摩擦/刑伤的触发点（落流年何宫即何领域发力）；流禄主该年进财/资源机会点；流昌/流曲主该年考试、签约、文书之助；流魁/流钺主该年贵人；流马主该年迁动/出行/岗位变动；煞星重逢（本命煞同宫再逢流煞）按《00-4》二之二第 2 条标注"煞星重逢"。
   - **流鸾/流喜（婚恋应期）**：⚠ **同层恒不可落命/夫**——流鸾支＝(3−流年支) mod 12，与流年命宫支（＝流年支）**奇偶恒相反**，故流鸾/流喜**永远落不到流年命宫、流年夫妻宫**（同层偶数位宫皆落不到），只可能落流年的**兄弟/子女/疾厄/交友/田宅/父母**六宫（原理见《01-6》第八节"同层落宫约束"）。有效读法：①落**本命**命宫/夫妻宫/子女宫（跨层）；②落**大限**命宫/夫妻宫/子女宫（跨层）；③落**流年子女宫**（同层唯一可用的婚恋宫）；④与本命红鸾天喜叠会（仅太岁年——流年支＝生年支——时同位）、与运鸾运喜叠会（跨层）。多层叠会（本命/大限/流年三层鸾喜同气）信号最强，可明确点出"此年婚缘动"；仅流年单层鸾喜，只说"此年人缘桃花较旺，利结识"。逢流煞同宫则桃花带磨，措辞留有余地，不得直断婚期。**禁止再写"流鸾入流年夫妻宫/流年命宫"式断语**（恒不可触发）。
4. **三盘叠宫关系**：流年盘与大限盘、本命盘的叠宫（JSON overlay 含 natal 叠宫信息）。

### 2.3 流年解读

1. **先定主场（不可跳过）**：流年命宫叠本命何宫＝**该年事项的主场与发生线**（家宅线／外途线／事业线／亲缘线……），先落这一条，再论四化。实证教训：只盯四化落宫会漏掉"这事发生在哪条线上"——同一笔财，流年命宫落田宅＝得于本地家宅线，落迁移＝得于外途线，断语方向完全相反。**互证时"发生地/主场"是独立对照维度，与事项本身并列核验**。
   - **主场须正向输出（不得只作排除项）**：定出主场线后，**必须接着写出"该主场线在本年触发了什么"**——不能只拿它去否定别的主题就收工。实证教训：曾算出"流年命宫落本命财帛宫"却仅用它排除"婚姻假设"，未追问"这条财帛线上本年发生了什么"，致该年最密的信号（限年同干、四化全叠）被搁置，主判接错主题。
   - **主题不在主场线时须附旁注**：用户点名问某一主题（婚姻、健康等）时，若该年主战场在**别的线**，须在结论后补一句"该年主战场在 X 线，宜另论"——否则"问婚姻只报婚姻"，会漏掉其他线上的重大转折。

2. **定三方四正（先取范围，禁凭记忆）**：流年专项宫的三方四正，**一律查《02-2》第一节"三方四正映射表"**——在该宫行上读取"对宫 / 三合宫1 / 三合宫2"，与本宫合成 {本宫, 对宫, 三合宫1, 三合宫2} 四宫，即本步的计分范围；宫名一律用**流年盘宫名**，**不得与本命盘、大限盘的同名宫混淆**。**禁止凭记忆填写、禁止脑内估算后直接使用**（若改用 +6/+4/+8 推导，须落笔逐宫写出四宫名核对；取法口径同《05-2》Step 2 第 0 步——错一宫则整盘计分全错）。该范围各宫的星曜取流年 JSON `overlay[]` 的 `natalStars`（该层 overlay 为 `{liunianPalaceName, natalBranch, natalPalaceName, natalStars[]}`）。

3. **三层读法**（《02-4》）：本命四化=底色、大限四化=过程、流年四化=**触发**；**不抵消，是叠加**——三层各讲各的层面，合成一个完整故事。

4. **吉凶计分与三层四化汇集（视角一·流年盘内·定档）**：
   - 煞忌按《00-4》计，**论流年时加计大限忌＋流年忌**（三层煞忌并计）；吉曜按《00-1》第一节动态辅佐计（**本命辅佐＋运辅佐＋流辅佐三层**，须分层标注来源）；四化修正按《00-1》第二节第 4 步。
   - **计分范围＝第 2 步所定"流年盘三方四正"**——**不得改以本命宫位或大限宫位为计分范围**；同一批地支位置在本命盘／大限盘上的宫名另由 `overlay[].natalPalaceName` 等字段反查，用于第 5 步。
   - **三层四化汇集（逐条列出）**：落在上述三方四正内的 **生年四化（底色）＋大限四化（过程）＋流年四化（触发）** 须**逐条列明，不得只列流年四化**；**同坐一宫**的读法调《02-4》§五之五（**不抵消、是叠加**）；碰撞定性分两路——**同层多化**查《03-3》第一节（该表覆盖同宫／对宫／三合照，**落于三合者烈度较轻、作牵引读**；**只定性、不入档位**），**跨层叠（生年×大限、生年×流年、大限×流年）**查《03-3》第四节（**限同宫**：双禄交临／双忌交临／禄解忌／忌破禄）；层级高低调《03-3》第二节（生年①>大限②>流年③>宫位自化④）。
   - **三层动态星同看（易漏，重点）**：《00-1》§一 明定"论流年计本命辅佐＋运辅佐＋流辅佐"——故 **大限动态星的吉曜（运魁/运钺/运昌/运曲/运禄）与流年动态星（流魁/流钺/流昌/流曲/流禄）落在该三方四正内者一并计入**，**漏运曜即漏计**（计分细则见 §2.2 第 3 条）；运羊/运陀、流羊/流陀按《00-4》二之二节分层减半计入煞忌。
   - **宫干四化（飞星）只作补充验证**（《03-3》第五节）：只用于佐证定语与观象三层，**不入本流年档位计分**。叠宫位置的宫干**不分层、只有一个**（本命该地支宫的宫干，《02-4》§五之一），故**不存在"大限各宫宫干""流年各宫宫干"，禁止自行推算**（引擎亦不输出该数据）。
   - **结构检索（虚破孤刑·独立一票）**：调《00-1》第二节第 6 条——上列均为**加减计分**，而"**虚／破／孤／刑**"属**结构性病征、在加减法里无权重**，故须**单独检索**：命中即**压档（至少半档）并写入定语**，**不受前几项计分覆盖**。检索范围为**流年盘三方四正**（宫名用流年盘宫名），四类结构的定义与"通则非穷举清单"操作口径同《05-2》Step 2 第 6 步。

5. **会照清单（视角二·本命盘／大限盘·定作用面，强制逐项枚举，枚举完方可进入下一步）**：流年是触发层，触发的"靶子"在本命盘和大限盘上——站在**本命盘／大限盘**视角，**坐、冲、照三档都要列，不得只列坐冲**（"照"是《00-4》独立 0.5 权重的档次，漏照即漏掉整档）。**枚举直接查流年 JSON 的 `branchLookup[12]`**（按 natalBranch 定序，含流年四化落宫 `scopeSiHua`/`scopePalaceName` 与流星落宫 `dynStars`），大限盘侧对照大限 JSON 的 `branchLookup`；**冲宫 = natalBranch ±6，照宫 = ±4/±8，禁止手工重建映射**：
   - 流年化忌**坐/冲/照**本命何宫、**坐/冲/照**大限何宫 → 该领域为该年触发点（坐＝受压、冲＝被冲动、照＝被牵动）；
   - 流年化禄/权/科**坐/冲/照**本命/大限何宫 → 该领域该年得助（禄=资源、权=主导、科=声名）；
   - 流羊/流陀**坐/冲/照**本命/大限何宫 → 该年摩擦发力领域；
   - 流年忌与生年忌/大限忌**同坐或同冲一宫** → **双忌交临**（《00-4》三节：+2、至少【重染】），应期加重，定语必须标注；
   - 流年忌与生年忌/大限忌**分处同一轴线两端（一坐一冲）** → **双忌夹冲**（《00-4》三节：+1、至少【轻染】）——是另一档加重，**不得混称"双忌交临"**；
   - 流年忌与生年忌/大限忌**互为三合照** → 只作"牵引 / 暗动"（《03-3》一节），**不入加重项、不升档**，定语可附注但不作加重依据；
   - **本命命宫/身宫/财帛/官禄/疾厄，或大限命宫/财帛宫/官禄宫被坐、冲、照时，必须写进定语。**

6. **定应期**：流年四化飞入叠宫位置 → 今年触发；大限＋流年四化同入 → 应期加倍；流年忌与生年忌／大限忌同宫或对照 → 忌忌叠加、应期加重（枚举见第 5 步）。

7. **流年专项**（用户问流年婚姻/财运等）：
   - **看流年对应宫位**（如流年夫妻宫、流年财帛宫），并按第 2～5 步走完"三方四正定范围 → 流年盘内定档 → 本命／大限盘会照定作用面"。
   - **回查底色（强制，两层）**：必须回查记录 md 中**该本命宫档位**（「三、本命总论」＝底色）与**该大限宫档位**（「五、大限记录」＝过程）作参照——本命＝底色、大限＝过程、流年＝触发（《02-4》§三/§五之五）；流年专项结论在该势能区间内展开，**不得越过本命／大限底色单论**（流年财帛宫配大限财帛宫、配本命财帛宫，余此类推）。
   - **叠宫互涉**：流年专项宫叠本命何宫、叠大限何宫 → 主题绑定（《02-4》§四）。**叠宫只定"什么事跟什么事绑在一起"，不定因果方向**——是"此影响彼"还是"彼影响此"，须由四化飞入/飞出/自化定（《02-4》§五之二/三/四）；**无四化指向时只写"两事纠缠"，不下因果**。
   - **不得套用同层联动表**：本步是跨层读法（《02-4》§八"叠宫＝纵向"）；《02-3》对宫互看主题表属同层横向，不可套用（如财帛的对宫是福德，财与官的同层关联走三合"命财官三角＝立身格局"）。

8. **结论按《00-1》四之三走"观象三层"**：流年是"触发"层（三层读法），同一触发在不同准备度下落点差异最大。三层依次写足——**能量**（该年触发的是哪股力、强度如何，须标象源：流年四化/叠宫/限年碰撞）→ **宫位**（触发落在哪一宫、该宫主何事）→ **含义**（这股力今年落此宫的象义倾向；好的一面与需留意的一面都写，**面向不懂命理的普通人须写足写通俗**，低位档必留转机）。末尾固定接**留意声明**：具体应验成哪件事因人因时而异，本报告不推定。**禁止对流年断言具体事件**。含义层的转译方向按情境档案校准——命主"当前最关心"的方面，相关含义写得最详。
   - **限年区分度硬规则**：流年观象的定位是**该年的触发点、强度变化与应期**，与大限的"十年结构性倾向"必须拉开层级——**流年含义层须以大限对照语开头：「承接」（大限基调的延续）/「放大」（大限已有之象今年加重）/「触发」（大限潜伏之象今年被点燃）/「反转」（与大限基调相逆的插曲），四选一**。写不出对照语者说明在重复大限内容，删除重写；禁止逐象照搬大限措辞。
   - **应期定位类提问须先按主题线筛年份（两级过滤，不得只按力度排序）**：问"哪一年结婚／何时发财"这类**应期定位**问题——① 先用"**流年专项宫（如夫妻宫、财帛宫）叠本命何宫**"筛出**线上年份**（婚姻类须落在命／夫／福／田等亲缘家宅线，财帛类须落财帛／田宅线）；② 再在线上年份内按四化、动态星、鸾喜强度排序。**禁止把"力度最强但不在线上"的年份排在前列**——实证：某例 2025 年力度最密（限年同干、四化全叠、红鸾坐流年命宫）但主场在本命财帛线，与婚姻主题无关，原判因按力度排序而占榜首致误。**主题线筛选优先于力度排序**。

9. 结论写入记录 md「六」。

## 三、纪律

- 大限/流年盘调出后**必须先过《05-0》校验三规并列全要素**（校验前置，取代复述确认）；本命盘的生辰确认关（《05-1》）仍强制，不在此列。
- 用户连续问多个流年：同一大限内无需重复取大限 JSON，只取新流年 JSON。
- 大限专项的三方四正一律按《02-2》第一节映射表**以宫名取**（大限盘宫名），**禁凭记忆／脑内估算**（表与公式恒等价、首选查表；用公式须落笔核对）；会照清单必须**坐/冲/照三档齐全**，不得只列坐冲；大限层计分**不得改以本命宫位为范围**。
- 流年专项的三方四正一律按《02-2》第一节映射表**以宫名取**（流年盘宫名），**禁凭记忆／脑内估算**（表与公式恒等价、首选查表；用公式须落笔核对）；会照清单必须**坐/冲/照三档齐全**；流年层计分**不得改以本命宫位或大限宫位为范围**；煞忌与辅佐**三层并计（生年＋大限＋流年），不得只列流年层**——尤其**运曜（运魁/运钺/运昌/运曲/运禄）不得漏计**。
- 一切解读可回溯：结论后注明依据（记录 md 章节 + 知识库文件）。
- **鸾喜（运鸾/运喜、流鸾/流喜）只按"跨层"或"同层子女宫"读**：同层鸾喜**恒不落命宫／夫妻宫／福德宫**（星与宫同源、地支奇偶恒反，见《01-6》第八节"同层落宫约束"）；**禁止写"运鸾入大限夫妻宫""流鸾入流年夫妻宫"式断语**——那是恒不可触发的格子。
- **应期定位类提问先按主题线筛年份**：先以"流年专项宫叠本命何宫"筛出**线上年份**，再在线上按四化／鸾喜强度排序；**禁止按力度排序后直接给结论**（详见 §2.3 第 8 步两级过滤）。
- 引擎口径为唯一权威源，**不再对照文墨天机**；如用户拿来文墨天机截图仅作参考，发现差异以引擎为准（差异项可记入记录 md「备注」供后续回归）。
