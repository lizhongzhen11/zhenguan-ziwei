# 贞观紫微 · 紫微斗数解盘 Skill

> 一套面向 AI Agent 的紫微斗数解盘技能：内置排盘引擎（真太阳时校正）+ 完整判定知识库 + 结构化解盘工作流。
> 不做"命定论"，只做**方向导航** —— 告诉你怎么走，不告诉你命定了。

## 这是什么

一个可以装进 AI Agent（WorkBuddy / Claude Code / Codex 等）的技能包。装上之后，
你给出**出生年月日时分 + 性别 + 出生省市**，它就能：

1. 调内置引擎排盘（不靠 AI 看图、不靠 AI 心算）；
2. 逐宫分析本命十二宫；
3. 按需展开专项宫位、大限、流年；
4. 最后产出一份藏青金配色的 HTML 报告。

### 设计上的三条底线

| 原则 | 含义 |
|---|---|
| **引擎排盘，不由模型推算** | 宫位干支、星曜、四化一律经 Node CLI 取 JSON。模型不识图、不凭八字自行推算 |
| **只给方向，不替决策** | 说"适合外出发展"，不说"你应该去上海"。呈现走能量→宫位→含义三层，不推定具体具象、不下单一结论 |
| **档位由命盘定，天地只改呈现** | 时代（三元九运）与地域环境只影响出口的转译方式，不改变吉凶强弱 |

### 三才定位

- **天盘** ＝ 时代与三元九运
- **地盘** ＝ 所处国家城市的现实环境（**可主动选择** —— 孟母三迁，换的就是地盘）
- **人盘** ＝ 紫微命盘

命盘刻画性格结构与势能分布，但不单独决定遭遇：同一场时代浪潮压下，千万人命盘千差万别
却同受其压；命盘决定的只是**你在风里的结构与走法**。

## 功能特性

- **引擎排盘权威化** —— 内置贞观紫微引擎（iztro 算法 + lunar.js），按省市经度做真太阳时校正（含均时差）。大限/流年盘含全量动态星（运/流 羊陀禄马昌曲魁钺鸾喜）。
- **完整知识库** —— 33 颗星曜档案、十二宫位体系（含三方四正公式、叠宫）、四化流转碰撞规则、格局检索（主星组合/朝拱/结构/四化/破格）、全域判定规则。
- **五步判定流程** —— 定体 → 辅 → 煞 → 化 → 格局，每宫结论必落档位，定语鼓励收尾。
- **观象三层** —— 每宫结论给「能量 → 宫位 → 含义」三层：这股能量是什么性质、落在哪一宫、该宫主什么（含义层写足写通俗，面向不熟命理的读者）；**不替命主猜"会变成哪件具体事"**——同一能量因人因地因时而异，此层留白，由命主自行留意。低档位含义层必留转机。
- **情境校准** —— 解读前轻量访谈现实处境，**含义层的落地方向**按情境校准 —— 盘面是地形，情境是出发点，同盘不同命因处境而异。
- **时运与地域环境校正** —— 叠加三元九运背景，确认命盘后追问发展地并联网检索当地实况，迁移/官禄/财帛/夫妻四宫按当地实况转译取象。
- **结构化报告** —— 藏青金主题 HTML：**三才定位**（天盘时代之运／地盘发展地环境／人盘命盘结构）+ 卷首语 + 十二宫分析表 + 强弱归因 + 易经卦象勉励 + 道德经勉励，卦象与章句均附白话解析与命盘落点。

## 快速开始

### 方式一：从 SkillHub 安装（WorkBuddy 用户）

在 WorkBuddy 的技能市场中搜索「贞观紫微」安装即可。

### 方式二：手动安装

```bash
git clone https://github.com/lizhongzhen11/zhenguan-ziwei.git ~/.workbuddy/skills/zhenguan-ziwei
```

> 若使用 Claude Code / Codex，克隆到对应的 skills 目录即可。

### 运行环境

排盘需要 **Node.js**（建议 18+）。引擎会按以下顺序自动查找：
`~/.workbuddy/binaries/node/versions/*/node` → 系统 `node`。无需额外 `npm install` ——
依赖库已内置在 `ziwei-chart/lib/`。

## 使用

在对话里直接给出生辰即可，例如：

```
2000-01-01 12:00 男 江苏南京
```

Agent 会按以下流程推进：

```
排盘建档 → 复述命宫/身宫/四化，等你确认生辰
   ↓
本命十二宫全分析
   ↓
按需专项（事业 / 财运 / 婚姻 / 外出 …）
   ↓
大限 · 流年
   ↓
生成 HTML 报告
```

也可以直接指定：

```bash
# 本命盘 JSON
node ziwei-chart/engine-cli.mjs 2000 1 1 12 0 male 江苏省 南京

# 本命盘 + 单文件排盘 HTML（file:// 双击可用）
node ziwei-chart/engine-cli.mjs 2000 1 1 12 0 male 江苏省 南京 --format html --name 匿名

# 第 4 个大限（按 startAge 升序，idx 从 0 起）
node ziwei-chart/engine-cli.mjs 2000 1 1 12 0 male 江苏省 南京 --daxian 3

# 大限 + 流年
node ziwei-chart/engine-cli.mjs 2000 1 1 12 0 male 江苏省 南京 --daxian 3 --liunian 2027

# 只给经度（生僻出生地）
node ziwei-chart/engine-cli.mjs 1987 11 13 15 30 female --longitude 119.48
```

> **注意**：城市名**不带**「市/县/区」后缀。带后缀会查库失败并静默回退到省会经度，
> 导致真太阳时偏移、时辰跨位、十二宫整体错位。

## 目录结构

```
├── SKILL.md                  # 技能入口：三才定位、能力边界、加载纪律、流程
├── 00-全局规则/              # 判断引擎（吉凶权重·层级制化·会照·污染度·时运地域）
├── 01-星曜/                  # 33 星档案（14 主星 + 六吉 + 六煞 + 禄存天马鸾喜姚池刑）
├── 02-宫位/                  # 宫位基础·关系映射（三方四正公式）·联动逻辑·叠宫
├── 03-四化/                  # 十天干四化表·四化定义·流转碰撞规则
├── 04-格局/                  # 格局总纲·主星组合·朝拱会照·结构格·四化格·煞格破格
├── 05-解盘工作流/            # 引擎调用规范·排盘建档·本命分析·大限流年·总结报告
├── ziwei-chart/              # 排盘引擎（Node CLI + 浏览器排盘 UI）
│   ├── engine-cli.mjs        # 命令行入口
│   ├── js/ziwei-engine.js    # 盘面生成、真太阳时、大限流年
│   ├── js/cities.js          # 省市经度库
│   ├── index.html            # 排盘 UI
│   └── lib/                  # 内置 iztro / lunar（见 THIRD-PARTY-NOTICES.md）
└── tests/                    # 命例观察与回归集
```

排盘产物（记录 md、HTML）由 Agent 写入**用户当前工作目录**，不写回本仓库。

## 引擎回归校验

改动知识库或引擎后，建议跑一遍回归：

```bash
cd ziwei-chart
# 1) 库可用性
node -e "globalThis.self=globalThis; const i=require('./lib/iztro.min.js'); const l=require('./lib/lunar.js'); console.log(typeof i.astro, typeof l.Solar)"

# 2) 本命回归（北京 116.4°E，真太阳时 -21 分 → 申时）
node engine-cli.mjs 2026 7 25 17 7 female 北京市 北京

# 3) 大限回归
node engine-cli.mjs 2026 7 25 17 7 female 北京市 北京 --daxian 3

# 4) 流年回归
node engine-cli.mjs 2026 7 25 17 7 female 北京市 北京 --liunian 2027
```

预期值见 `05-解盘工作流/05-0 引擎调用规范.md` 第七节。
