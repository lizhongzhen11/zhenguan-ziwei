# 00-4 煞忌污染度评估

> **【AI 执行指令 · 职责边界】**
> 凡需判断某宫位凶性烈度，或他文件引用"煞忌污染度"时，**必须执行本文件的计分流程，禁止凭感觉估计**。
> 本文件只回答"凶的烈度"，不回答"吉的高度"——吉的高度（辅佐力量）由《00-1 吉凶权重计算标准》判定。
> 庙旺落陷修正规则调《00-2 星曜层级与制化法则》；坐/冲/照的定性调《00-3 三方四正会照原则》。

---

## 一、统计范围

- **评估单位**：单个宫位。取该宫的**三方四正**（本宫 + 对宫 + 两个三合宫，共 4 宫）作为一个评估整体。**"该宫"指当层盘上的该宫**——论本命＝本命盘该宫、论大限＝大限盘该宫、论流年＝流年盘该宫（同名的本命宫与大限宫 / 流年宫**不是同一组地支**，**禁止以本命同名宫代替**）。三方四正推导用《02-2》开头公式，禁止凭记忆。
- **计入项**：六煞（擎羊、陀罗、火星、铃星、地空、地劫）+ 化忌（含生年忌、自化忌、大限忌、流年忌，各自规则见下方计分表）。
- **化忌按分析层级计入**：论本命 → 计生年忌；论大限 → 加计大限忌；论流年 → 再加计流年忌。
- **动态煞星按分析层级计入（v1.1.0）**：论大限 → 加计运羊/运陀；论流年 → 再加计流羊/流陀。运/流煞为**应期触发之星，烈度低于本命煞**，按本命煞**减半计分**且逐层递减（计分表见第二节末）。
- **动态吉曜不计入污染度**：运禄/运昌/运曲/运魁/运钺、流禄/流昌/流曲/流魁/流钺归《00-1》动态辅佐计数（v1.1.0）；运马/流马只作动向参考（与本命天马"不计入辅佐"同例）；运鸾/运喜/流鸾/流喜只作婚恋/喜庆应期取象（读法见《05-3》）。
- **不计入**：天刑、阴煞等杂曜凶性只作断语取象参考，不计分。
- **空宫借星时的煞忌处理**：本宫为空宫时，对宫的煞星（羊陀火铃空劫）**不借入**——仍留在对宫，按对宫→本宫的"冲"关系计 1 分（例：官禄空宫借夫妻主星，夫妻宫的陀罗不借入官禄，而是作为对宫煞星冲官禄，计 1 分）。对宫主星附带的化忌随主星借入，按"坐"计 2 分（见《00-2》空宫借星规则）。

## 二、基础计分

| 煞忌所在位置 | 每颗计分 |
|---|---|
| 本宫（坐） | 2 分 |
| 本宫（自化忌） | 1 分（此条为自化忌专用；生年忌坐仍计 2 分；自化忌只按坐计，不向外产生冲/照计分） |
| 对宫（冲） | 1 分 |
| 三合两宫（照） | 每颗 0.5 分 |

> **自化忌说明**：自化忌 = 该宫天干引发的化忌落在本宫（"自己搞砸自己"），烈度低于生年忌（生年忌是先天结构性缺陷，自化忌是该宫内在动力引发的自我消耗）。按 1 分计入污染度，定语中须标注"该宫有自化忌，主自我消耗/自我纠结"。**自化忌只按"坐"计 1 分，不产生冲对宫、照三方的连锁计分**（忌未飞出本宫，无外延；他宫不再因这颗自化忌星的位置计冲/照）。**视同自化（同一星曜同时带生年忌与本宫自化忌）：不重复计分**——按生年忌 2 分计一次，断语层作"忌力加重、自我消耗叠加"表述。若同宫为**不同星曜**分带生年忌与自化忌，各自分别计分（生年忌 2 分 + 自化忌 1 分 = 3 分），定语中标注"生年忌+自化忌叠加，诸事反复自困"。

## 二之二、动态煞星计分（运羊/运陀/流羊/流陀，v1.1.0）

> 运星（大限层）/流星（流年层）是**应期触发之星**——本命煞是结构性的"地形"，运流煞是时限性的"天气"。天气烈于一时、不毁地形，故减半计分且逐层递减。

| 煞星位置 | 运羊/运陀（论大限时） | 流羊/流陀（论流年时） |
|---|---|---|
| 本宫（坐） | 1 分 | 0.5 分 |
| 对宫（冲） | 0.5 分 | 0.25 分 |
| 三合两宫（照） | 0.25 分 | 0.125 分 |

**规则**：
1. **运煞与流煞只在对应层级计入**：论本命不计任何运/流煞；论大限只计运煞；论流年计运煞+流煞（与本命煞、大限忌、流年忌叠加）。
2. **运/流煞与本命煞同宫（如本命擎羊又逢运羊）**：称"煞星重逢"，该煞触发应期——分数仍按上表各自计，但定语必须标注"X煞重逢，此限/此年该煞之性发作"，不得静默叠加。
3. **运/流煞不触发加重项**：第三节的羊陀夹、三煞同蹲等加重项**只按本命煞判定**，运/流煞不参与（防三层煞叠算把污染度推爆）。**加成项的"本宫"指当层盘上的被评估宫**（同第一节"该宫"）——论大限＝大限盘该宫、论流年＝流年盘该宫，**禁止以本命同名宫代替**；即判"夹 / 同蹲"时，用**本命煞所处地支**与**当层盘该宫地支**做邻接比对（地支位置固定，层级只改"该宫"的取法）。
4. **动态吉曜归《00-1》动态辅佐（v1.1.0）**：运禄/运昌/运曲/运魁/运钺、流禄/流昌/流曲/流魁/流钺与本命同星同例计数（单见 1、成对 2、禄 1），只在对应层级计入且须标注来源；**运马/流马只作动向参考，运鸾/运喜/流鸾/流喜只作婚恋/喜庆应期取象**，均不计分。

## 三、加重项（满足即加，可叠加）

| 情形 | 加分 |
|---|---|
| 羊陀夹本宫（禄存坐本宫，擎羊陀罗分居前后邻宫） | +1 |
| 火铃夹本宫 | +1 |
| 空劫同宫、或空劫夹本宫 | +1 |
| 双忌交临（生年忌与大限忌、或大限忌与流年忌，**同坐或同冲一宫**） | +2，且最终档位**至少为【重染】** |
| 双忌夹冲（两忌分处一宫轴线两端，一坐一冲。例：生年忌坐命、大限忌坐迁移冲命） | +1，且最终档位**至少为【轻染】** |
| 本宫三煞及以上同蹲 | +2 |

## 四、减免项

> **本节"本宫"指当层盘上的被评估宫**（同第一节"该宫"）——论本命＝本命盘该宫、论大限＝大限盘该宫、论流年＝流年盘该宫，**禁止以本命同名宫代替**。

| 情形 | 减免 |
|---|---|
| 本宫有紫微（须辅佐充足，见《00-1》） | -1 |
| 本宫有天府且府库充盈（见禄存/化禄；空库不减免，见《00-2》） | -1 |
| 本宫辅弼 / 昌曲 / 魁钺成对同宫 | 每对 -0.5，最多 -1 |
| 煞星入庙（以引擎 `brightnessText` 为准） | 该煞分数 ×0.5 |

- 总分下限为 0，不出现负分。

## 五、分档与断语基调

| 档位 | 总分 | 断语基调 |
|---|---|---|
| 【清净】 | ≤1 | 煞忌不扰，主星本性正常发挥 |
| 【轻染】 | >1 且 ≤3 | 有波折不致命，主星本性打折，断语留余地 |
| 【重染】 | >3 且 ≤5 | 主星本性明显扭曲，所主事项多阻滞；须指出吉星救应所在以定减轻程度 |
| 【破染】 | >5，或触发"双忌交临"/"三煞同蹲" | 该宫所主事项以凶断，防重大损失、刑伤、破败；**除非构成反转格局（火贪、铃贪等）方可不破** |

> **区间无缝**：四档取值区间首尾相接、不留空隙——凡算出分值必落某档。**禁止把档位自行四舍五入或"就近归档"**（旧版写作"1.5–3""3.5–5"，致 1.25 / 3.25 / 5.25 一类分值无归属，实测已踩：某限财帛宫算得 1.25 被径直写作"轻染"，属自行补档）。

> **【档位归口】本档是"污染度输入档"，不是最终档位**：最终档位须经《00-1》第三节"辅佐 × 污染矩阵"合成——同为【破染】，辅佐充足落"**苦撑**（有救应不致崩，守成待时）"、辅佐有力落"**危局**（持重避险）"、辅佐不足落"**败局**（重压破败，以凶断）"。故本条"以凶断"**只在辅佐不力时适用**（矩阵"危局／败局"格）；**辅佐充足时不得按"以凶断"直读**（实证：某流年财帛宫算得破染，同时三奇齐会、左右魁钺在宫，事实为"破而后立、未崩"）。**先出污染档 → 再查《00-1》第三节矩阵 → 方定最终档位**，两步不得合并。

## 六、使用规则

1. **先算分，后断语**。任何凶断必须能回溯到本文件的计分过程；输出时注明档位，不必罗列计算细节。
2. 同一命盘论多个宫位时，**每宫独立计分**。
3. **格局反转例外**：若该宫构成火贪、铃贪等特殊格局（见格局层），先按格局判定；格局成立则不适用【破染】断语。
4. 本文件常与《00-1》的辅佐力量分档组合使用（辅佐 × 污染矩阵，见《00-1》第三节）。
