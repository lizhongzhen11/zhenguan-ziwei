## 一、 四化碰撞速查表（同宫 / 三方四正通用）



> 适用场景：**同一宫位内**，或**同一组三方四正（本宫 + 对宫 + 两合宫）之内**，同时出现两个及以上四化（本宫天干 / 生年天干 / 大限天干等不同来源）。
> 
> **落位强度（本表只定性质、不定烈度）**：同宫（坐）与对宫（冲）可照表直读；落于三合（照）者同此性质而烈度较轻，读作"牵引 / 暗动"，**不用"冲破""交战"一类重词**（"冲破"专指坐、冲）。烈度计分另按既有规则——《00-4》二节（煞忌：坐 2 ＞ 冲 1 ＞ 照 0.5）、《00-3》二节（吉星：坐 ＞ 照 ＞ 冲；煞星：坐 ≈ 冲 ＞ 照）。
> 
> **边界（与《00-3》五节的分工）**：本表扩至三方四正者，只指**四化力量层面的交互**（叠加 / 抵消 / 牵引）；《00-3》五节"会照不产生新性质"所指的**星曜双星互涉**仍只发生在同宫，本表不越界。
> 
> **档位归口（本表只定性、不入档位）**：本表产出的是**性质定性**（大吉 / 吉 / 凶 / 吉凶参半…），**不直接换算档位**。档位效应由既有路径承担——**已立格**者走《00-1》第二节第 5 步格局例外（三奇嘉会 / 双禄交临 / 禄合鸳鸯 / 科名会禄）；**凶性**碰撞并入《00-4》加重项；**吉性未成格**者（如禄权相逢、权科相逢）只作定语呈现。**禁止自行把"大吉 / 吉"折算成升档量**——避免与禄 / 科各自的半档上调重复计。
> 
> 

|碰撞组合|判定结果|
|---|---|
|化禄 + 化权|大吉，事业财运双收，但需防过于强势|
|化禄 + 化科|吉，名利双收，温和得财|
|化权 + 化科|吉，以专业能力掌权，名声在外|
|**化禄 + 化忌**|**吉凶参半，"禄逢冲破"，主先得后失、因财惹祸，需重点评估煞星数量**|
|**化权 + 化忌**|**凶多吉少，权力斗争中受挫，或强势反遭反噬**|
|**化科 + 化忌**|**凶中有救，虽遇困境但有贵人相助，化科可缓解但无法消除化忌之凶**|
|化禄 + 化权 + 化科|大吉，成"三奇嘉会"格（三方四正会照即成立，格局要件见《04-4》§三奇嘉会），主大富大贵|
|**三吉化 + 化忌**|**吉凶交战，需按00-4 煞忌污染度评估》精确计算**|



## 二、 四化层级优先级（谁的力量最大？）

> 当不同来源的四化叠加在同一宫位时，按以下优先级判断影响力：
> 
> 



|优先级|四化来源|影响力|说明|
|---|---|---|---|
|**1（最高）**|**生年四化**|一生底色|命盘先天格局，贯穿命主一生，力量最持久|
|**2**|**大限四化**|十年运势|当前十年的主题，力量次于生年但强于流年|
|**3**|**流年四化**|一年运势|当年触发事件，力量最短暂但最具体|
|**4**|**宫位自化**（含离心／向心两式）|内在变化|该宫位天干引发的四化，代表该宫位人事物的"自我演化"（离心＝自我耗散／向心＝受对宫牵动）|



> **判定原则**：高层级四化定基调，低层级四化为触发事件。例如：生年化禄在财帛宫（一生财运好），流年化忌也进入财帛宫（该年财运受阻），则判定为"该年财运虽有波折，但先天底子好，不会伤筋动骨"。
> 
> **叠宫场景**（本命/大限/流年宫位同地支）下多化"不抵消、是叠加"的具体读法，调《02-4 叠宫》（底色/过程/触发三层读法）。
> 
> 



## 三、 宫位自化规则（自化唯一定义来源）

> 宫位自化 = 该宫位的天干引发的四化，落于**本宫（离心自化）**或**对宫（向心自化）**；两式合计为自化，方向相反——离心＝能量由本宫向外耗散，向心＝能量由对宫向本宫汇聚。本节为自化定义的**唯一权威来源**；叠宫场景下自化的应用与因果方向，调《02-4 叠宫》五步之二。
>
> **与引擎字段的对应（防误记）**：引擎 `selfTransforms` 输出的**两式皆属自化**——`离心`＝四化落**本宫**（本宫自化，星坐本宫）、`向心`＝四化落**对宫**（向心自化，星坐对宫）。取用时**一律按 `type` 区分并注明落宫**；记录 md 的"自化"栏**两式皆收**，但**不得把向心条目笼统写作"某宫自化X"**（其星实坐对宫，如此记法会指错宫位、取象全反）。
> 
> 



|自化类型|定义|解盘逻辑|
|---|---|---|
|**离心自化禄**|本宫天干使**本宫内**某星化禄|该宫位人事物"自我增益"，主自得其乐、自我满足|
|**离心自化权**|本宫天干使**本宫内**某星化权|该宫位人事物"自我强化"，主自我要求高、控制欲强|
|**离心自化科**|本宫天干使**本宫内**某星化科|该宫位人事物"自我收敛"，主注重形象、爱面子|
|**离心自化忌**|本宫天干使**本宫内**某星化忌|该宫位人事物"自我消耗"，主自我纠结、自我否定，**是最需要关注的自化类型**|
|**向心自化禄**|本宫天干使**对宫内**某星化禄|对宫的人事物向本宫"输送增益"，主因外部／他人他事而得利、受滋养|
|**向心自化权**|本宫天干使**对宫内**某星化权|对宫的人事物向本宫"施压牵引"，主受外部强势牵引、被要求或被推动|
|**向心自化科**|本宫天干使**对宫内**某星化科|对宫的人事物向本宫"输送名声"，主因外部评价而受关注、得名|
|**向心自化忌**|本宫天干使**对宫内**某星化忌|对宫的人事物向本宫"压入消耗"，主受外部牵累、被他人他事拖累，**取象与离心自化忌相反**|

> **两式区别一句话**：离心＝**自己**向外泄（自我消长）；向心＝**外部**朝自己来（被对宫牵动）。记录与呈现时须标明星之落宫（本宫／对宫），否则两者混淆。

> ⚠️ **离心自化忌的特殊性**：离心自化忌代表该宫位的人事物会"自己搞砸自己"（能量外散耗泄）。例如：夫妻宫自化忌（忌星坐本宫），主命主在感情中自我折磨、疑神疑鬼；财帛宫自化忌（忌星坐本宫），主命主赚钱后自己挥霍或投资失误。
>
> ⚠️ **向心自化忌取象相反**：星坐**对宫**，主对宫的人事物向本宫压入、本宫被外部牵累——**不是"自己搞砸自己"**。如：夫妻宫向心自化忌（忌星坐官禄宫），主感情受事业／外部压力牵累，而非命主自我折磨。**两者的推论方向南辕北辙，记录时务必注明落宫。**
> 
> 



## 四、 大限四化叠本命四化规则

> 当大限四化与本命（生年）四化落入**同一宫位**时，产生"叠加效应"（本表产物为**格局名**，故范围与《04-4》各格要件一致：双禄交临 / 双权交临须**同入一宫**；双忌交临按《00-4》三节另含"**同冲一宫**"）：
> 
> **不适用范围**：本表只管同宫（及双忌的"同冲一宫"，另见《00-4》三节加重项"双忌夹冲"）。落于**三合（照）**方向的跨层四化交互**不入本表、不称格局名**，按《03-3》第一节作"牵引 / 暗动"读（烈度递减）。
> 
> 



|叠加组合|判定结果|
|---|---|
|大限化禄 叠 本命化禄|**双禄交临**，大吉，该十年此宫位人事物极度繁荣|
|大限化忌 叠 本命化忌|**双忌交临**，大凶，该十年此宫位人事物遭受严重破坏，**必须触发00-4 煞忌污染度评估》**|
|大限化禄 叠 本命化忌|**禄来解忌**，先凶后吉，该十年前半段困难、后半段好转|
|大限化忌 叠 本命化禄|**忌来破禄**，先吉后凶，该十年前半段顺遂、后半段生变|
|大限化权 叠 本命化权|**双权交临**，权力极度膨胀，易与人产生严重冲突|

> **通用原则（三盘两两叠加通用）**：吉化叠吉化 = 吉应加倍；忌叠忌 = 双忌交临，计分见《00-4》加重项（含双忌夹冲）；禄忌互叠 = 先 X 后 Y（按上表"禄解忌/忌破禄"定性）。大限×流年叠加以此类推，应期读法调《02-4》第三步。



## 五、 飞星四化基础规则（进阶）



> 飞星四化 = 从 A 宫的天干引发四化，飞入 B 宫，代表 A 宫的人事对 B 宫的人事产生作用。
> 
> 



|飞星路径|定义|解盘逻辑示例|
|---|---|---|
|**命宫化禄飞入财帛**|命宫天干使某星化禄，该星落在财帛宫|命主"以自身能力赚钱"，主主动求财、财运顺遂|
|**命宫化忌飞入夫妻**|命宫天干使某星化忌，该星落在夫妻宫|命主"执着于感情"，主感情中付出过多、易受伤害|
|**财帛化禄飞入田宅**|财帛宫天干使某星化禄，该星落在田宅宫|命主"赚钱后置产"，主财富能积累、购置不动产|
|**官禄化忌飞入疾厄**|官禄宫天干使某星化忌，该星落在疾厄宫|命主"工作劳累伤身"，主事业压力大、影响健康|



> ⚠️ 飞星四化是紫微斗数的高阶技法，解盘时**优先判断生年四化和大限四化**，飞星四化作为补充验证使用。
> 
> 叠宫场景下"一飞触发多层主题"的飞星应用，调《02-4 叠宫》五步之三/四。

### 五之二、飞星自循环吉应（补充验证·操作定义）

> 本节为《00-1》五步判定第四步"飞星自循环吉应"的操作定义。
> 全盘48条飞星全量追踪复杂度太高，本节只纳**最直接、最有判断价值的一种**：宫干飞出的禄/权/科落在该宫自己的三方四正中（**其中化权只作注记、不计入上调**，见下"计入规则"）。

**判定流程**：
1. 取该宫的**宫干**（＝该宫的天干。从排盘 JSON `palaces[]` 中该宫的 `stem` 字段取，**为数字索引，须以 `STEMS[stem]` 转为天干名**；字段说明同《05-0》第三节）。⚠ 宫干由**年干 ＋ 宫位地支**共同推算，**不是"某地支固定配某天干"**，禁止凭地支默记。
2. 查《03-1 十天干四化表》，找到该天干对应的禄/权/科分别落在哪颗星上。
3. 在排盘 JSON 中找到这些星的落宫——若落在该宫的**三方四正**（本宫+对宫+两合宫）任一宫中，则计入。

**计入规则**：
- 飞星禄落在该宫三方四正 → 上调半档
- 飞星权落在该宫三方四正 → **不计入上调**（同《00-1》第二节第 4 步：权属双面量、不入单向势能刻度；**孤立化权不入档位**）；若与吉化同宫或会照，定语附"刚烈/掌控"注记。
- 飞星科落在该宫三方四正 → 上调半档
- 多个飞星自循环吉应 → 合并只计一次上调半档（不叠加）
- **上调上限**：无论生年四化上调 + 飞星自循环上调共几个触发，总计上调不超过一档。
- **飞星忌不纳入**：避免与《00-4》生年忌重复计重。

**示例**：迁移宫地支为未、天干为己。己干四化：武曲禄、贪狼权、天梁科、文曲忌。查武曲在福德宫（照迁移·三合）、贪狼在夫妻宫（照迁移·三合）→ 飞星**禄**照迁移宫三方四正（贪狼权同照，但**不计入上调**，只作"刚烈/掌控"注记）→ 触发飞星自循环吉应，上调半档。

**报告呈现**：在记录 md 和 HTML 报告的五步摘要/定语中注明"飞星自循环"及其来源，如：`化(破军禄上调+飞星自循环武曲禄贪狼权照上调)`。

## 六、 四化逢煞通则（四化 × 六煞的共性规则）

> 星曜个性的"遇煞质变"见各星曜档案（01 层）模块三；本节只写四化本身与煞星相遇的共性通则。

| 组合 | 通则 |
|---|---|
| 化禄逢空劫 | **禄落空亡**：吉力大减，防"虚喜"——看似有得终难得，或得而复失 |
| 化禄逢羊陀火铃 | 吉力打折，兼看煞之性质（逢羊＝财中带刑；逢火铃＝财来急去也急） |
| 化权逢煞 | 掌权遇阻、强势招怨；煞重时"刚极易折"，防因争致败 |
| 化科逢煞 | 贵人助力减弱，名声受损；化科解厄之力仍在但变薄 |
| 化忌逢空劫 | ⚠ 流派分歧：一说"忌逢空则凶性被空掉一部分"，一说"空忌同宫凶上加凶（落空＋执念）"。**本库取定前者**（凶性略减但不消，执念被空劫"掏空"——宜守不主动求财，反而能放下执念化解部分凶性） |
| 化忌逢羊陀火铃 | 凶性叠加引燃，按《00-4》计分（化忌视同煞） |
> 
>
