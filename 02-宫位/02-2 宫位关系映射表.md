> **【三方四正推导规则（AI 必须内化）】**
> 
> 12宫成环，序号：命0 兄1 夫2 子3 财4 疾5 迁6 友7 官8 田9 福10 父11。
> 
> - 对宫 = 本位 + 6 (mod 12)
> 
> - 三合宫 = 本位 + 4 (mod 12) 与 本位 + 8 (mod 12)
> 
> - 三方四正 = 本宫 + 对宫 + 两三合宫（共4宫）
> 
> - 任何宫位的三方四正，必须按此公式推导，禁止凭记忆填写。
>
> - 【与第一节表的关系】本公式为三方四正的**唯一权威定义**；第一节"三方四正映射表"即本公式的**已校验展开**，二者恒等价。**执行时首选查表**（免 mod 运算、免出错）；表覆盖不到或存疑时，回退本公式推导。**查表与推导两路皆可**——唯一被禁的是"**凭记忆／凭印象直接填写**"。
> 
> - 【防呆】若 AI 环境不支持 mod 运算，可用等价写法：
> 
>     - 结果 = 加法结果；若 结果 ≥ 12，则 结果 = 结果 − 12。（因为最多只加8，不会≥24，减一次12足够）
>

## 三、 三合三角形表（四组等边三角，+4/+8）



> 三合宫在命盘上呈等边三角形，共4组，每组3宫。注意：对宫不属于三合，三方四正 = 三合三角(3宫) + 对宫(1宫)。
> 
> 



|三合组|三角宫1|三角宫2|三角宫3|
|---|---|---|---|
|Ⅰ|命宫|财帛宫|官禄宫|
|Ⅱ|兄弟宫|疾厄宫|田宅宫|
|Ⅲ|夫妻宫|迁移宫|福德宫|
|Ⅳ|子女宫|交友宫|父母宫|



> **校验方法**：任取一宫，其三方四正 = 它所在的三合三角(3宫) + 它的对宫(1宫)。
> 
> 例：迁移宫在三角Ⅲ\{夫,迁,福\}，对宫=命 → 迁移的三方四正 = \{迁,夫,福,命\} ✓
> 
> 例：田宅宫在三角Ⅱ\{兄,疾,田\}，对宫=子 → 田宅的三方四正 = \{田,兄,疾,子\} ✓
> 
> 例：官禄宫在三角Ⅰ\{命,财,官\}，对宫=夫 → 官禄的三方四正 = \{官,命,财,夫\} ✓
