# 02-4 叠宫

# 一、什么是叠宫

**一句话定义：** 不同时间层级的盘（本命盘、大限盘、流年盘……），它们的宫位落在了同一个地支位置上。

> **举例：** 你的本命命宫在"寅"，大限命宫也在"寅"，流年命宫也在"寅"——三个盘的命宫叠在了同一个位置，这就是叠宫。
> 
> 

# 二、叠宫 ≠ 同宫

- **同宫**：两颗星在同一个宫位里。维度是空间（同一张盘内）。举例：紫微和天府都在寅宫。

- **叠宫**：多层盘的宫位落在同一个地支位置。维度是时间（跨盘）。举例：本命命宫在寅，大限财帛宫也在寅。

# 三、三层盘各自的角色

- **本命盘**：你是什么样的人（先天格局）。比喻：你手里的牌。

- **大限盘**：这十年你大概经历什么（十年主题）。比喻：这局牌的规则。

- **流年盘**：今年具体发生什么（当年事件）。比喻：这一手出什么牌。

**它们的关系不是"谁影响谁"，而是层层嵌套：**

- 本命限定上限（你先天能走多远）

- 大限划定主题（这十年围绕什么事）

- 流年触发事件（今年具体哪件事发生）

# 四、叠宫意味着什么

**叠宫 = 两个（或多个）主题被绑在了一起。**

比如：本命夫妻宫在"申"，大限财帛宫也在"申"。

→ 意思是：这十年，"婚姻"和"财运"这两件事纠缠在一起了。

**注意：叠宫只告诉你"什么事跟什么事绑在一起"，不告诉你谁导致谁。**

# 五、叠宫分析流程（三步走）

## 第一步：找叠宫

把本命盘、大限盘、流年盘的十二宫位排出来，看哪些宫位落在了同一个地支位置。

## 第二步：看四化，定因果方向

### （一）核心原则（先记住这个，后面所有步骤都基于此）

叠宫就是同一个位置。一个位置上叠了多个主题，可能跨层级（比如同时是流年某宫、大限某宫、本命某宫）。

四化飞入一个位置，就是同时飞入了这个位置上**所有叠着的主题**，不分层级，不需要逐层看。

四化从一个位置飞出，就是从这个位置上**所有叠着的主题**同时飞出，不分层级。

### （二）看叠宫内部有没有自化

**怎么判断：** 叠宫位置的宫干引发的四化，如果落在叠宫本位（也就是自己飞给自己），就是**离心自化**；若落在叠宫本位之对宫，则为**向心自化**。两式皆属自化（《03-3》第三节为唯一定义来源）；本节以离心式为主，向心式取象见《03-3》。

**举例（示意，非任一真实命例）：** 先明确叠宫情况：

- 某一宫位叠了三个宫位：流年财帛宫、大限官禄宫、本命田宅宫。

- 这个位置的宫干是癸。

- 癸干引发贪狼化忌。

- 贪狼正坐在该位本位上。

这就是**离心自化忌**。

**怎么解读（自化定义统一调《03-3》第三节，唯一权威来源）：**

**离心自化** = 该宫人事物"自我演化"——能量在这个位置**内部打转**：好处（禄）不易向外扩展，问题（忌）不易向外扩散但也不易解决。（**向心自化**方向相反：对宫能量向本位压入、本位被牵动。）自化禄/权/科/忌的具体取象以《03-3》为准，本节不重复定义。

**怎么定因果方向：**

**离心自化**没有外部因果，是内部闭环（向心自化系对宫飞入本位，属外部因果）。解读时从两个方向看：

- 从本命往流年看（由里及表，看发展）：本命田宅宫自化忌是根源，这十年影响了大限官禄宫的整体状态，今年在流年财帛宫爆发出来。根基（家宅）问题是根，事业方向受困是过程，财务问题是表现。

- 从流年往本命看（由表及里，找根源）：流年财帛宫自化忌是表现，暴露了大限官禄宫这十年的困境，根源在本命田宅宫。财务问题是表象，事业方向受困是中间层，根基问题是根源。

两个方向不矛盾，是同一件事的两种视角。

### （三）看外部宫位有没有四化飞入叠宫

**怎么判断：** 找到叠宫位置以外的其他宫位，看那些宫位的宫干引发的四化，有没有落在叠宫位置上。如果有，那个外部宫位就是"因"，叠宫位置就是"果"。

**举例（示意，非任一真实命例）：** 先明确叠宫情况：

- **甲干之宫**叠了三个宫位：流年官禄宫、大限财帛宫、本命迁移宫。

- 这个位置的宫干是甲。

- 甲干引发廉贞化禄。

- 廉贞落在另一个位置上。

再看廉贞落在哪里：

- 廉贞落在某个位置上，这个位置叠了三个宫位：流年田宅宫、大限福德宫、本命父母宫。

所以：**该位宫干（甲干）**引发廉贞化禄，廉贞飞入了流年田宅宫（大限福德宫、本命父母宫）所在的叠宫位置。

**怎么解读：**

直接说：流年官禄宫化禄入流年田宅宫，同时大限财帛宫化禄入大限福德宫，同时本命迁移宫化禄入本命父母宫。

一个飞化，同时触发三个主题：

- 今年的事业给今年的家宅／置产带来好处和机会。

- 这十年的财务给这十年的精神生活带来好处和机会。

- 先天的外出发展给先天的长辈关系带来好处和机会。

三个解读全部成立，不需要分层级逐一看，因为飞入的是同一个位置。

**怎么定因果方向：**

外部宫位是因，叠宫位置是果。

本例中：**因位**（流年官禄宫、大限财帛宫、本命迁移宫）是因，**果位**（流年田宅宫、大限福德宫、本命父母宫）是果。

**四化性质决定影响类型：**

- 化禄飞入 = 带来好处、机会、资源。

- 化权飞入 = 带来控制、压力、主导权。

- 化科飞入 = 带来名声、贵人、表面光鲜。

- 化忌飞入 = 带来问题、损失、纠缠。

### （四）看叠宫的宫干有没有四化飞出到外部

**怎么判断：** 看叠宫位置的宫干引发的四化，有没有落在叠宫位置以外的其他宫位上。如果有，叠宫位置就是"因"，外部宫位就是"果"。

**举例（示意，非任一真实命例）：**

先明确叠宫情况：

- **癸干之宫**叠了三个宫位：流年田宅宫、大限福德宫、本命父母宫。

- 这个位置的宫干是癸。

- 癸干引发破军化禄。

- 破军落在另一个位置上。

再看破军落在哪里：

- 破军落在某个位置上，这个位置叠了三个宫位：流年官禄宫、大限财帛宫、本命迁移宫。

所以：**该位宫干（癸干）**引发破军化禄，破军飞入了流年官禄宫（大限财帛宫、本命迁移宫）所在的叠宫位置。

**怎么解读：**

直接说：流年田宅宫化禄入流年官禄宫，同时大限福德宫化禄入大限财帛宫，同时本命父母宫化禄入本命迁移宫。

一个飞化，同时触发三个主题作为"因"：

- 今年的家宅／置产之事，给今年的事业带来好处和机会。

- 这十年的精神状态，给这十年的财务带来好处和机会。

- 先天的长辈关系，给先天的外出发展带来好处和机会。

三个解读全部成立。

**怎么定因果方向：** 叠宫位置是因，外部宫位是果。

**四化性质决定影响类型：** 同上，禄权科忌分别对应好处、控制、名声、问题。

> **补充：三禄叠加 ≠ 必发大财**——禄讲的是"**顺利与确定性**"，好处的**具体形式随宫位与星曜而定**：落官禄宫主"**事业转型顺利**"，不等于财数。破军属"先破后立"，得禄只让过程少阻、**初期回报仍有限**。故三层禄叠加应读作"**此事确定能成、过程顺利**"，**不得读作"一定会赚大钱"**。

**禄是"好处"，好处的具体形式看宫位和星曜。在财帛宫是钱，在官禄宫是机会，在夫妻宫是缘分。**

### **（五）不同层级的四化同时飞入同一个叠宫位置**

**什么情况：** 本命四化、大限四化、流年四化，性质不同（比如一个是忌、一个是权、一个是禄），但都飞入了同一个叠宫位置。

**核心原则：不抵消，是叠加。各讲各的层面，合在一起是一个完整的故事。**

- 本命四化 → 底色、根源 → 回答"这件事本质上是什么性质"

- 大限四化 → 过程、阶段 → 回答"这十年怎么经历的"

- 流年四化 → 触发、应期 → 回答"今年发生了什么"

**举例：** 本命化忌、大限化权、流年化禄，都飞入同一个叠宫（流年官禄宫、大限财帛宫、本命迁移宫）。

- 本命忌（底色）：这个人天生在变动和对外发展上有阻碍，一辈子都在。

- 大限权（过程）：这十年在财务上需要主动争取、硬扛，不轻松。

- 流年禄（触发）：今年事业上出现机会，顺利。

合在一起读：这个人天生在变动上有阻碍（忌是底色），这十年一直在硬拼（权是过程），今年终于有了突破口（禄是今年）。

**比喻：**

- 忌 = 这条路本来就难走（地形崎岖）。

- 权 = 这十年一直在爬坡（很吃力）。

- 禄 = 今年到了一个平坦路段（有收获）。

路还是那条路，地形没变，但今年这一段是好的。

**反过来：本命禄、大限权、流年忌。**

- 禄是底色：底子好，先天条件有利。

- 权是过程：这十年一直在主动经营。

- 忌是今年：今年这个节点出了问题。

底子好不代表今年不出事，只是长期基础是好的，今年的忌是暂时的。

**解读顺序：先读底色（本命），再读过程（大限），最后读今年的触发（流年）。**

## 第三步：看流年，定应期

大限告诉你"这十年有这个主题"，但具体哪一年发生，看流年：

- 流年四化飞入叠宫位置 → 今年触发

- 流年没有四化飞入 → 今年不触发

# 六、叠宫的层级与力量

叠的层数越多，力量越大：

- **本命 + 大限**（两层叠）：力量中等。这十年有这个主题。

- **本命 + 流年**（两层叠）：力量中等。今年先天格局被激活。

- **大限 + 流年**（两层叠）：力量中等。今年十年主题被触发。

- **本命 + 大限 + 流年**（三层叠）：**力量最强**。先天格局、十年主题、当年事件全部对准同一个点。

# 七、叠宫与四化的配合

这是叠宫分析中最关键的部分：

- **大限四化飞入叠宫位置** → 这十年内此事必发（大限定了基调）

- **流年四化飞入叠宫位置** → 今年此事触发（流年定了时间）

- **大限 + 流年四化同时飞入** → 今年必发，且力量加倍

- **本命化忌 + 大限化忌 + 流年化忌 同入一宫** → 极凶，三层忌星叠加

- **本命化禄 + 大限化禄 + 流年化禄 同入一宫** → 极吉，三层禄星叠加

# 八、叠宫与宫位联动的关系

- **宫位联动（02-3）**：横向。同一层盘内，宫与宫的关系。回答的问题是"看这件事要参考哪些宫？"

- **叠宫（本篇）**：纵向。跨时间层级，盘与盘的叠加。回答的问题是"这件事什么时候发生？跟什么事绑在一起？"

**两者结合使用的顺序：**

> 先用宫位联动（横向）确定要看哪些宫 → 再用叠宫（纵向）确定什么时候触发、跟什么事纠缠。
